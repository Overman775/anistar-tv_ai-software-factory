# Счётчик «В списке: N» рядом с заголовком «Серии»

## Зачем

По наблюдению пользователя, счётчик справа от заголовка «Серии» на странице
аниме сейчас показывает только число. Пользователь подтвердил, что речь
именно об этом элементе; в прототипе он подписан «В списке: N».

## Чего хочу

Показывать число с сопровождающим текстом, как в
[прототипе](../../prototype/index.html). Подтверждённый пользователем элемент —
счётчик рядом с заголовком «Серии» в полной карточке аниме:
[AnimeScreen](../../lib/packages/features/anime/presentation/screens/anime_screen.dart)
выводит только `${episodes.length}`. В функции `detail()`
[прототипа](../../prototype/app.js) этому месту соответствует точная строка
`В списке: ${a.episodes}`; пример для Фрирен — «В списке: 28».

В образце счётчик расположен рядом с заголовком и имеет вторичный цвет;
оформление задают `.detail-episodes .count` в
[основных стилях](../../prototype/app.css) и
[адаптивных стилях](../../prototype/responsive.css).
На телефоне Flutter сейчас использует «Серии · N» в
[MobileAnimeContent](../../lib/packages/features/anime/presentation/widgets/mobile_anime_content.dart).
Нужно уточнить, относится ли пожелание и к этой компоновке.

## Что важно сохранить

Число должно отражать длину фактически полученного списка серий.
Демонстрационное `a.episodes` из прототипа не заменяет production-данные:
сведения о запланированном выпуске в `seriesInfo` не доказывают наличие
доступных видеоссылок. Сохранить нумерацию, порядок, выбор серии и отметки
просмотра по [контракту карточки](../specs/12_anime_details.md).

Подпись должна оставаться читаемой при масштабировании текста, без изменения
переходов фокуса по [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md).
Для будущей правки важны существующие проверки раскладки и навигации
[списка серий](../../test/packages/features/anime/presentation/screens/episode_list_regression_test.dart)
и [визуальный контракт](../specs/11_visual_system.md).

## Что пока неясно

Область подтверждена: количество в секции «Серии». Отдельная серия в прототипе уже подписана
«Серия N» (`episode()`), а Flutter формирует ту же подпись через
[EpisodeCaption](../../lib/packages/features/anime/presentation/widgets/episode_caption.dart).
У [AnimeCard](../../lib/packages/features/catalog/presentation/widgets/anime_card.dart)
нет числового бейджа количества серий; в `inspectorContent()` прототипа
есть рейтинг, категории и сообщение об обновлении, отдельного счётчика нет.
Подпись «В списке:» на эти элементы не распространяется.
