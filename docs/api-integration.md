# API и HLS

## Endpoint parser

Адрес передаётся при запуске:

```bash
--dart-define=ANISTAR_API_URL=https://parser.example.com/
```

Если параметр отсутствует, используется `http://10.0.2.2:8001/` на Android и `http://127.0.0.1:8001/` на остальных платформах. Для физического TV укажите LAN-адрес или HTTPS endpoint. Cleartext разрешён только для локальной Android-разработки.

## Контракт

Каноническая схема находится в `openapi/anistar.openapi.json`. Клиент использует:

| Операция | Назначение |
| --- | --- |
| `listAnime` | страница каталога |
| `getAnimeDetail` | данные аниме |
| `listAnimeEpisodes` | доступные серии |
| `getPlaybackInfo` | новая HLS-сессия и выбранное качество |

`getPlaybackInfo` возвращает относительный `manifest_path`. Приложение разрешает его относительно `ANISTAR_API_URL` и отдаёт только нативному плееру.

## Правила воспроизведения

- Не кэшируйте `manifest_path` и не заменяйте его прямой CDN-ссылкой.
- Parser может снизить запрошенное качество; UI показывает фактически выбранное.
- При ошибке или истечении токена запросите новую playback-сессию.
- WebView не используется.

## Обновление клиента

Вначале обновите и проверьте схему в соседнем проекте parser, затем скопируйте её в `openapi/` и выполните:

```bash
bash tool/generate_anistar_api.sh
```

Скрипт требует OpenAPI Generator 7.23.0, генерирует `packages/anistar_api/`, применяет зафиксированный workaround и запускает генерацию `built_value`.
