# ADR-0006: Прямой AniStar на Android

- **Статус:** Accepted
- **Дата:** 2026-10-10
- **Связи:** Сетевой контракт описан в [руководстве по сети и HLS](../04_network_and_playback.md). Проверка сайта и CDN описана в разделе [live smoke](../05_development_and_testing.md#9-проверка-с-живым-аккаунтом).

## Контекст

Проверки Android подтвердили получение каталога, карточки и playlist обычным Dart HTTP, а также native HLS 360p/720p с Referer и явным форматом. Проверенное зеркало доступно без браузера и parser-сервера.

## Решение

- Android-клиент использует AnistarSource, bytes/charset, DOM и JSON5 как данные.
- Feature repositories преобразуют DTO сайта в domain.
- Native video_player получает полный CDN URI, Referer и `VideoFormat.hls`.
- Один автоматический refresh получает новую ссылку и сохраняет позицию и паузу. Ручной retry начинает новый бюджет.
- Зеркало задаётся HTTPS origin через `ANISTAR_MIRROR_URL`.
- Клиент поддерживает онлайн-просмотр. Скачивание и офлайн не входят в scope.

## Последствия

Клиент работает без посредника, но зависит от разметки сайта и доступности зеркала для IP пользователя. Интерактивная CAPTCHA не обходится.
