# ADR-0003: Публичные границы core и TV UI kit

## Статус

Принято — 2026-07-19

## Контекст

После выделения OpenAPI-клиента и result-потока общие классы начали
использоваться несколькими features. Без явной границы код мог бы снова
перейти к глубоким импортам конкретных файлов, а TV-экраны — к копированию
одних и тех же заголовков и focus-состояний.

## Решение

- `lib/packages/core/core.dart` — единственная публичная точка импорта для
  транспорта, `Either`, `Failure`, `BaseRepository` и локальных storage.
- `core` не содержит feature-моделей, UI, навигации или бизнес-логики
  каталога/плеера.
- `ui_kit` экспортирует только токены темы и маленькие TV-примитивы:
  backdrop, focus target, состояния и заголовок секции.
- Сложные feature-виджеты (карточка аниме, hero, player overlay) остаются
  рядом с feature до появления второго реального потребителя.

## Последствия

Положительные: единые контракты, меньше глубоких импортов, повторяемый
TV-ритм отступов и заголовков, простые unit-тесты core.

Ограничения: UI kit намеренно не копирует корпоративные navigation, DI,
WebView и mobile-компоненты из `mobile-app`; новый компонент добавляется
только после повторного использования.
