# 📖 Доменный глоссарий | AniStar TV

Значения терминов в требованиях, коде и тестах. Владельцы указаны в [карте ответственности](01_02_feature_responsibilities.md).

## 1. Доступ, аккаунт и зеркало

| Термин | Значение |
| :--- | :--- |
| Доступ (`AuthAccess`) | Режим доступа приложения, отдельный от загрузки и ошибок входа. [Модель](../lib/packages/features/auth/domain/auth_access.dart), [вход](specs/01_authentication.md). |
| `UnknownAccess` | Режим доступа ещё неизвестен. Отсутствие аккаунта само по себе не означает выбор гостевого режима. |
| `UnauthenticatedAccess` | Подтверждённого аккаунта и выбранного гостевого режима нет. |
| `AnonymousAccess` | Явно выбранный доступ без аккаунта. Выбор гостевого режима действует до перезапуска. |
| `AuthenticatedAccess` | Доступ с подтверждённым аккаунтом и его функциями. |
| Зеркало / origin | Зеркало задаёт адрес сайта. Origin состоит из схемы, хоста и порта. Сессия привязана к origin. [Зеркала](specs/05_mirrors.md). |
| Область данных аккаунта | Привязка к аккаунту и origin. Ответы из прежней области отбрасываются. Привязки задаёт [app composition](../lib/app/app_container.dart). |

## 2. Аниме, каталог и поиск

| Термин | Значение |
| :--- | :--- |
| Краткая карточка (`AnimeSummary`) | Элемент выдачи каталога, поиска или избранного. [Модель](../lib/packages/features/catalog/domain/models/anime_summary.dart). |
| Полная карточка (`AnimeDetails`) | Подробности аниме. `AnimeScreenData` объединяет их с сериями. [Карточка](specs/12_anime_details.md). |
| ID / slug | Идентификаторы источника. Запрещено выводить их из заголовка или считать глобальными для всех зеркал. [ADR-0010](adr/0010-normalized-anistar-contract.md). |
| Страница выдачи (`AnimePage`) | Порция результатов и сведения для продолжения загрузки. [Пагинация](specs/03_page_loading.md). |
| Фильтр (`CatalogFilter`) | Ссылка на каталог сайта с подписью. `label` отображается, исходный `path` используется в запросе. [Фильтры](specs/09_catalog_filters.md). |
| Часть (`AnimePart`) | Связанное произведение в порядке просмотра. Открытие части не считается просмотром серии. [Карточка](specs/12_anime_details.md). |
| Номер серии | Номер источника, отдельный от позиции в списке и ID медиа. В нумерации бывают пропуски. [Воспроизведение](specs/04_playback.md). |
| Поисковый запрос | Текст, отправленный явным действием пользователя. Для сравнения записей истории применяется отдельная нормализация. [Поиск](specs/13_search.md). |
| История поиска | Локальные запросы в области origin и гостя/аккаунта. Гостевые запросы могут сохраниться после перезапуска приложения. [Поиск](specs/13_search.md). |
| Неизвестное значение | Отсутствующие данные в nullable-поле. Сохраняйте `null` при отсутствии значения. [ADR-0010](adr/0010-normalized-anistar-contract.md). |

## 3. Избранное и просмотр

| Термин | Значение |
| :--- | :--- |
| Статус избранного | Принадлежность к избранному аккаунта. `true` и `false` подтверждают наличие и отсутствие, `null` означает неизвестность. [Избранное](specs/02_favorites.md). |
| Изменение избранного | Запрос желаемого состояния, который завершается подтверждением сайта. [Избранное](specs/02_favorites.md). |
| Воспроизведение началось | Native controller сообщает фактическое `isPlaying == true`. [Просмотренные серии](specs/07_watched_episodes.md). |
| Просмотренная серия | Серия с подтверждённой сайтом отметкой начала воспроизведения. Отметка не измеряет прогресс. [Просмотренные серии](specs/07_watched_episodes.md). |
| История просмотра | Подтверждённые сайтом отметки серий аккаунта. [Просмотренные серии](specs/07_watched_episodes.md). |
| Продолжить / смотреть заново | Выбор эпизода для TV-списка по загруженным сериям и подтверждённым отметкам. Временная позиция не восстанавливается. [Правило выбора](../lib/packages/features/anime/domain/models/anime_watch_action.dart), [карточка](specs/12_anime_details.md). |
| Playback session (`PlaybackSession`) | Источник, серии, качества и параметры доступа для native controller. [Модель](../lib/packages/features/player/domain/models/playback_session.dart). |
| Запрошенное / выбранное качество | Пользовательский запрос и качество, которое подобрал playback repository с учётом доступности. [Воспроизведение](specs/04_playback.md). |
| Подписанный media URI | Адрес источника с параметрами доступа. Передаётся целиком и исключается из логов. [Сеть и HLS](04_network_and_playback.md). |
| Обновление playback session | Повторное получение данных источника для воспроизведения. [Воспроизведение](specs/04_playback.md). |

## 4. Как использовать и обновлять глоссарий

Используйте эти значения в задачах, именах и тестах. При смене смысла обновите строку и связанные спецификации. Новая строка нужна, если различие влияет на поведение или устраняет неоднозначность. Лимиты, переходы и ошибки описывайте в спецификации. Расхождение кода и спецификации указывайте в задаче.
