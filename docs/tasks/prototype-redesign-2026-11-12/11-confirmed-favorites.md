## 1. Context and expected outcome

Любая поверхность показывает подтверждённое избранное текущего аккаунта.

## 2. Task scope (`implemented`)

1. TV-избранное получает общую ленту с заголовком «Избранное», собственными страницами и действиями. Метка закладки поступает из общего подтверждённого статуса во все карточки, включая поиск, скрывается у гостя и в самой выдаче избранного. Прямое действие используют TV-сведения и полная карточка аккаунта.
2. Первый системный повтор OK открывает действия постера один раз. Отпускание удержания не открывает карточку и не запускает действие панели. Закрытие возвращает фокус и не отменяет отправленную операцию.
3. Неизвестный статус безопасно доступен для перечитывания. Занятое действие сохраняет фокус и не дублируется. Показать изменение после операции и свежего чтения сайта; при отказе сохранить прежнее подтверждённое значение и дать явный повтор. Не повторять мутацию автоматически. Гость не вызывает аккаунтную операцию, старый аккаунт/origin не меняет текущий статус. При удалении последнего избранного TV возвращается в меню. Повторную активацию занятого действия и попытку отправить уже подтверждённое желаемое состояние проверить без лишней мутации.

## 3. Deferred work (`deferred`)

- **Behavior:** Удержание пальца с отменой при движении и без повторной активации при отпускании в новой мобильной сетке.
  - **Closing task:** mobile-shell-and-grids-15
  - **Temporary behavior:** Существующие мобильные действия остаются доступны через текущую сетку и используют подтверждённый статус. Открытие панели само по себе не отправляет мутацию.

## 4. Architectural context

- **Scope:** lib/packages/features/favorites.
- **Reuse:** Favorites владеет статусом и сериализацией операций, Auth — доступом. Действия и статус потребляются через существующие доменные контракты.
- **Critical decisions:**

  - D-01. Применить визуальные роли handoff через общий UI Kit и определять нативный профиль по устройству. Размеры служат ориентирами в logical pixels. Крупный текст сохраняет действия без обрезки. У визуальных 36 для метаданных область касания 48 без пересечения соседних целей. Дополнительной внешней рамки у ролей из handoff нет.
  - D-02. Объединить TV-выдачи в одну композицию и сохранить плитки выбора жанров. Лента сохраняет положение при изменении сведений и раскрытии меню. Действия привязаны к актуальному выбору.
  - D-03. Привязать TV-подгрузку к видимому слоту и хранить контекст отдельно по источнику. Подгрузка действует при наличии следующей страницы, в том числе в избранном и фильтрах. Состояние изолировано по origin, доступу, разделу, фильтру или запросу.
  - D-04. При входе показывать свёрнутую карточку и запускать выбранную серию. Правило продолжения применяется в TV-списке при известных сериях. В карточке убираются отдельная главная кнопка просмотра, счётчик «В списке» и Hero постера из каталога. Переход страницы сохраняется.
  - D-07. Использовать действующие контракты доступа, поиска, избранного и плеера. Минимум поиска 2, порция из четырёх, 19/29 записей, специальные слова, искусственные ошибки и тестовое видео принадлежат демонстрации.
