# Карточка аниме | AniStar TV

Спецификация задаёт платформенно независимый сценарий полной карточки аниме, частей и серий. Парсинг и форма данных принадлежат [спецификации загрузки страниц](03_page_loading.md), избранное — [спецификации избранного](02_favorites.md), а история просмотра — [спецификации просмотренных серий](07_watched_episodes.md).

## Состав карточки

Полная карточка показывает постер, название, доступные метаданные и описание. Доступные секции располагаются в таком порядке: полное название, постер и основные сведения, действия просмотра и избранного, сюжет, сообщение об обновлении и исходная дата, сведения о выпуске/озвучке, порядок просмотра, затем серии. TV и мобильная компоновки используют одни данные. В коротком мобильном альбомном окне действие просмотра остаётся доступным под прокручиваемым содержимым в единственном экземпляре. Запрос дополнительных деталей только из-за фокуса карточки не вводится.

Метаданные необязательны. Если сайт не предоставил значение, UI не показывает пустую метку и не подменяет его выдуманным значением. Исходная дата обновления показывается без преобразования в другую дату. Отображение рейтинга и отметки избранного следует [общей визуальной системе](11_visual_system.md) и подтверждённым значениям из спецификаций 02 и 03.

Действие избранного находится прямо на карточке и доступно только подтверждённому аккаунту. Гостю кнопка избранного и предложение войти ради него не показываются. Вызов операции без аккаунта не отправляет запрос. Начальное, занятое, подтверждённое и ошибочное состояния следуют [спецификации избранного](02_favorites.md). UI не меняет серверное состояние до подтверждения.

## Части и серии

Части являются отдельными объектами и не смешиваются с эпизодами. Парсер сохраняет порядок документа, полную подпись и исходную ссылку из скрытого или видимого блока порядка просмотра. Для текущего экрана с надёжно определённым ID показывается «Открыто». Это состояние обозначает текущую карточку, а не доступность по аккаунту и не просмотр серий.

При выборе другой части открывается её полная карточка внутри приложения по поддерживаемой ссылке. Текущий пункт не добавляет дубликат маршрута. Возврат восстанавливает исходную часть и контекст списка. Ссылка с неизвестным ID не получает отметку «Открыто». Неподдерживаемая ссылка остаётся подписью и не открывает внешний адрес. Если блока порядка нет, секция скрывается.

Рядом с заголовком «Серии» показано «В списке: N», где N — длина фактически полученного списка серий, включая ноль. Список расположен от большего номера к меньшему. На TV он использует три колонки, на телефоне — одну серию в ряд. Карточка серии показывает изображение на общей тёмной градиентной подложке, номер, собственное название и подтверждённую отметку просмотра; отдельного Play нет, активируется вся карточка. Отдельное выбранное состояние серии и текущий фокус не подменяют серверную отметку просмотренной серии. Ошибка загрузки и пустой список не считаются доступным списком для запуска. Детали извлечения номеров и media URL находятся в спецификациях 03 и 07.

При ограниченной высоте TV-области карточки и скелетоны сохраняют общую геометрию; высота ячейки растёт по содержимому и масштабу текста, а список прокручивается. Три колонки сохраняются. В узкой карточке серии превью сохраняет `16:9` и может уменьшаться по высоте; текст продолжает системно масштабироваться. `MediaCardMetrics` использует реальные стили, ширину и `TextScaler` карточки для расчёта общей высоты изображения и текстовой области. `EpisodeCaption` формирует визуальную подпись и полную доступную метку серии с её статусом просмотра. Правило полного доступного имени описано в [визуальной системе](11_visual_system.md).

Описание и метаданные не дублируют одно и то же значение. Год, жанры и режиссёр показываются один раз. Сохраняются уникальные дополнительные сведения и исходные ссылки-переходы для пригодных фильтров. Ссылка без подходящего значения остаётся текстом; отсутствующее значение не создаёт пустую плашку. Метки фильтров используют значок списка с фильтром из UI Kit.

## Главное действие просмотра

Главная кнопка выбирает серию только по доступным сериям и серверным отметкам `viewing: true`. Новая локальная система прогресса, позиция просмотра, процент досмотра и отметка окончания не добавляются. Успешное начало воспроизведения сохраняет существующий смысл отметки сайта.

Если отметок нет, кнопка «Смотреть» запускает серию с наименьшим доступным номером. Если отметки есть, кнопка выбирает доступную серию с наименьшим номером строго больше наибольшего номера, подтверждённого сайтом. Ранние пропуски ниже этой границы не выбираются автоматически.

| Серии, отмеченные сайтом | Доступные серии | Основное действие |
| :--- | :--- | :--- |
| Нет | 1, 2, 3 | «Смотреть» → 1 |
| 2, 3 | 1, 2, 3, 4, 5 | «Смотреть» → 4 |
| 1, 3 | 1, 2, 3, 4 | «Смотреть» → 4 |
| Все доступные | 1, 2, 3 | «Посмотреть снова» → 1 |

Если между максимальной отмеченной серией и концом списка нет доступной серии с большим номером, действие меняется на «Посмотреть снова» и запускает серию с наименьшим доступным номером. Например, при доступных 1, 3 и 5 и отметке 3 запускается 5; пропуск 4 не создаёт несуществующую серию. Если список не содержит серии, запуск недоступен и доступно объяснение или восстановление. Наличие серии без пригодного HLS не обещает успешного запуска: применяется ошибка источника из [спецификации воспроизведения](04_playback.md).

Ручной выбор серии всегда запускает выбранную доступную серию, независимо от основного действия. До подтверждения нового старта список может показывать только уже подтверждённые сервером отметки. Ошибка записи отметки не отменяет воспроизведение и не создаёт локальную отметку.

## Платформенное управление и восстановление

На TV карточка и её вложенные действия доступны с пульта согласно [TV-взаимодействию](06_tv_interaction.md). На телефоне действия доступны касанием и системной навигацией согласно [мобильному взаимодействию](10_mobile_interaction.md). Платформенные различия не меняют состав карточки и правило выбора серии.

Возврат из плеера сохраняет выбранную часть и контекст карточки. Если карточка уже закрыта, навигация возвращает пользователя в исходный раздел каталога по его правилам. Поворот телефона сохраняет playback controller и выбранную серию.

- [Фильтры каталога](09_catalog_filters.md) задают переход к карточке из отсортированной выдачи.

- [Выбор основного действия просмотра](../../lib/packages/features/anime/domain/models/anime_watch_action.dart) вычисляет следующую или повторную серию из доступных серий и подтверждённых отметок.
- [UI Kit](../../lib/packages/ui_kit/README.md) содержит подтверждённые публичные компоненты отображения.
