# Избранное | AniStar TV

Избранное принадлежит аккаунту AniStar на сайте. Постоянного локального списка нет. UI хранит только временные подтверждённые статусы и revision; они уничтожаются вместе с protected router.

## Статус и чтение

Статус имеет три значения: `true` — добавлено, `false` — не добавлено, `null` — неизвестно. Неизвестность нельзя превращать в `false` и показывать неподтверждённое действие.

GET `/index.php?do=favorites&cstart={page}` возвращает HTML списка. Номер страницы начинается с 1. Pagination поддерживает query `cstart` и `/favorites/page/{page}/`. Также применяются общие [правила страниц](03_page_loading.md) для charset, карточек, ID 9493, deduplication и errors.

Карточки избранного читаются внутри `#dle-content`, чтобы рекомендации вне списка не попадали в него. Пустой список принимается в двух случаях: сайт явно сообщает об отсутствии закладок либо `#dle-content` пуст в полной авторизованной странице. Во втором случае title должен содержать «Мои закладки», canonical должен указывать `do=favorites` на текущем origin, а страница должна содержать допустимую logout-ссылку. Такой ответ вернул живой сайт для пустого тестового аккаунта. Отсутствующий контейнер, guest page, чужой canonical и неизвестная разметка остаются ошибкой.

| HTML control текущего anime ID | Статус |
| :--- | :--- |
| `doFavorites(id, 'plus')` | `false`: сайт предлагает добавить |
| `doFavorites(id, 'minus')` | `true`: сайт предлагает удалить |
| href с `do=favorites&id=id&doaction=add` | `false` |
| href с `do=favorites&id=id&doaction=del` | `true` |
| Нет control / control другого ID / противоречивые действия | `null` |

Скрипты не выполняются: `onclick` и `href` читаются как данные. Правая панель действий запрашивает свежую карточку независимо от значка на плитке. Для getStatus проверяются соответствие `detail.id` выбранному ID и наличие определённого статуса.

## Изменение статуса

Операция задаёт желаемое значение, а не слепой toggle.

Сначала проверяются slug и соответствие числового префикса `animeId`. Затем запрашивается свежая `/{slug}.html` и читается текущий статус. При неизвестном статусе операция останавливается с ошибкой. Если статус уже равен желаемому, он возвращается без запроса изменения.

`dle_skin` читается из inline script как JSON5 string. Допустимы только `[a-zA-Z0-9_-]`, длина 1–64. Если безопасного значения нет, операция завершается ошибкой без подстановки произвольного default.

Изменение выполняется GET `/engine/ajax/favorites.php` с `fav_id`, `action=plus|minus`, `skin`, `alert=0`. Передаются Cookie текущей сессии, Referer карточки и `X-Requested-With: XMLHttpRequest`.

Ответ должен содержать однозначный control того же ID с действием, соответствующим новому статусу. Затем карточка загружается повторно. Её ID и статус должны подтвердить результат. Только после этого repository возвращает успех и UI обновляет состояние.

HTTP 200 с error, пустой fragment, control другого ID, противоречивый fragment или несовпадение свежей карточки дают ошибку. Fragment подтверждает ответ операции, а карточка — сохранённое состояние сайта.

## Повтор, согласованность и закрытие панели

Mutating GET явно исключён из transport retry. Автоматический повтор при timeout, потерянном ответе или смене зеркала запрещён, поскольку сайт мог уже применить действие. Пользователь повторяет операцию вручную; свежая карточка сначала определяет фактическое состояние.

FavoritesController допускает одно изменение одновременно для всего UI. Повторный вызов получает Failure ожидания. Optimistic star не используется. При ошибке busy снимается, а прежний confirmed state остаётся. В этом случае панель предлагает перечитать статус.

После успеха known status обновляется, revision увеличивается. Значок главной страницы, кнопка detail и открытый список избранного должны согласоваться с подтверждённым результатом. Удаление из списка вызывает его перезагрузку. Смена раздела или ручной refresh сбрасывают временный кеш, чтобы увидеть изменения другого клиента. Автоматического push/polling нет.

Закрытие панели через Back, «Закрыть» или наружное касание не означает отмену уже отправленного запроса и не откатывает сайт. Завершившаяся операция может обновить controller, если его scope ещё существует; закрытый widget не обновляет своё состояние. После смены аккаунта или зеркала актуальный статус читается заново.

## Обновление списка и TV-действия

На mobile ручной refresh — жест вниз от начала списка, в том числе пустого. Он делает новый GET первой страницы и сохраняет текущие карточки/статусы при ошибке. Временный кеш инвалидируется после успеха, если за время запроса не было нового подтверждённого изменения. Индикатор ждёт ответ сайта; повторные жесты не дублируют запрос. Контракт UI и gesture-тесты: [мобильное взаимодействие](10_mobile_interaction.md).

Долгое касание / удержание OK открывает выезжающую панель справа; само открытие ничего не меняет. Панель использует общий TvSideSheet по [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md). После закрытия фокус возвращается к карточке; если удалена последняя карточка избранного, фокус возвращается к пункту левого меню. Detail предоставляет кнопку добавления/удаления. Правила удержания: [TV-взаимодействие](06_tv_interaction.md).
