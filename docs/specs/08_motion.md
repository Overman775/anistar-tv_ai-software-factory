# 🎬 Анимации | AniStar TV

## 1. Принципы

Анимация объясняет переход между состояниями и сохраняет связь с выбранным сериалом. Без пружин, вращения, сильного zoom и последовательного появления каждой серии. Управление пультом не ждёт завершения декоративного эффекта.

Как в RC Mobile App, длительности и кривые принадлежат UI Kit. Feature использует AppMotion, навигация остаётся в app. Дополнительные animation-пакеты не нужны.

## 2. Токены

| Токен | Значение / назначение |
| --- | --- |
| fast | 160 мс: focus, звёздочка, вкладка, controls, переход player |
| standard | 240 мс: прокрутка к focus |
| page / pageReverse | 280 / 200 мс: открытие / закрытие карточки сериала |
| enterCurve / exitCurve | easeOutCubic / easeInCubic, без overshoot |
| shimmer | 1100 мс: цикл skeleton |
| durationOf / reducedOf | Учитывают disableAnimations и accessibleNavigation |

Playback timeout, refresh budget и удержание OK — поведение функций; это не длительности декоративных анимаций.

## 3. Постер

Одинаковый TvPosterHero с тегом `anime-poster-{id}` используется в каталоге, избранном и карточке сериала. Скругление сохраняется в overlay; прямоугольник движется напрямую, без дуги. Cached image не запускает отдельный fade внутри Hero.

AnimeRoute получает выбранный AnimeSummary через временный `$extra`. Постер доступен в первом кадре AnimeSkeleton, до ответа сайта; Skeletonizer его не закрашивает. PlayerRoute передаёт тот же extra родительской карточке, чтобы постер сохранялся после возврата из player. Extra не добавляет URL постера в query и не заменяет данные repository.

Если HTML пришёл во время Hero, skeleton с постером остаётся до завершения входного route transition. Затем показываются подробности. Offstage layout, которым HeroController измеряет конечную позицию, не считается завершением перехода. Поздний ответ после Back не возвращает экран и не создаёт новую анимацию.

При открытии без extra используется обычный skeleton; отсутствие постера или ошибка загрузки изображения не блокируют переход. Возврат в каталог/избранное сохраняет выбранную вкладку, focus и прокрутку. Если исходная карточка уже не существует, применяется обычный переход страницы.

## 4. Страницы и элементы

Карточка сериала появляется с fade и небольшим вертикальным сдвигом 2% высоты. Player использует только fade: native video не масштабируется и не участвует в Hero. Back проигрывает обратный переход.

Смена Главная/Избранное даёт короткий fade-in единственного нового дерева. Исходящий каталог не удерживается ради crossfade: это исключает дублирование Hero-тегов, focus и запросов. Подтверждённая сайтом звёздочка плавно появляется/исчезает; это не оптимистическое изменение избранного.

Focus-масштаб, рамка, прокрутка и controls используют durationOf. Эффекты не меняют выбранную серию, статус аккаунта или позицию воспроизведения.

## 5. Доступность и проверки

При disableAnimations или accessibleNavigation durationOf возвращает ноль; HeroMode отключает полёт постера, страницы и вкладки переключаются сразу, shimmer заменяется статическим цветом. Видимый focus сохраняется.

Регрессии проверяют Hero из обеих вкладок до HTTP, завершение загрузки в середине полёта, обратный переход, быстрый Back и оба режима отключения анимаций. Android E2E проверяет focus, избранное, переходы detail/player, native HLS и возврат; статические goldens защищают финальный вид. Плавность на физическом TV проверяется отдельно.
