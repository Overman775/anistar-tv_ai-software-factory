# 🎬 Анимации | AniStar TV

## 1. Принципы

Анимация объясняет переход между состояниями и сохраняет связь с выбранным сериалом. Без пружин, вращения, сильного zoom и последовательного появления каждой серии. Управление пультом не ждёт завершения декоративного эффекта.

Ориентир поведения и характера переходов — YouTube для телевизоров по [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md). Длительности и кривые ниже — собственные токены AniStar TV, а не измерения стороннего приложения. Они принадлежат UI Kit; feature использует AppMotion, навигация остаётся в app. Дополнительные animation-пакеты не нужны.

## 2. Токены

| Токен | Значение / назначение |
| --- | --- |
| fast | 160 мс: focus, звёздочка, смена раздела, controls, переход player |
| standard | 240 мс: раскрытие/сворачивание левого меню, затемнение каталога, прокрутка к focus |
| page / pageReverse | 280 / 200 мс: открытие / закрытие карточки сериала; правая панель использует page (280 мс) в обоих направлениях |
| enterCurve / exitCurve | easeOutCubic / easeInCubic, без overshoot |
| shimmer | 1100 мс: цикл skeleton |
| durationOf / reducedOf | Учитывают disableAnimations и accessibleNavigation |

Playback timeout, refresh budget, удержание OK, ускорение seek (500 мс повтор) и idle timer controls (4 секунды) — поведение функций; это не длительности декоративных анимаций.

## 3. Постер

Одинаковый TvPosterHero с тегом `anime-poster-{id}` используется в каталоге, избранном и карточке сериала. Скругление сохраняется в overlay; прямоугольник движется напрямую, без дуги. Cached image не запускает отдельный fade внутри Hero.

AnimeRoute получает выбранный AnimeSummary через временный `$extra`. TvPosterHero использует один исходный memory-cache key во всех размерах: изменение bounds в полёте не запускает новый decode с заглушкой. Остальные AppNetworkImage сохраняют resize по layout/DPR. Постер доступен в первом кадре AnimeSkeleton, до ответа сайта; Skeletonizer его не закрашивает. PlayerRoute передаёт тот же extra родительской карточке, чтобы постер сохранялся после возврата из player. Extra не добавляет URL постера в query и не заменяет данные repository.

Если HTML пришёл во время Hero, skeleton с постером остаётся до завершения входного route transition. Затем показываются подробности. Offstage layout, которым HeroController измеряет конечную позицию, не считается завершением перехода. Поздний ответ после Back не возвращает экран и не создаёт новую анимацию.

При открытии без extra используется обычный skeleton; отсутствие постера или ошибка загрузки изображения не блокируют переход. Возврат в каталог/избранное сохраняет выбранную вкладку, focus и прокрутку. Если исходная карточка уже не существует, применяется обычный переход страницы.

## 4. Страницы и элементы

Карточка сериала появляется с fade и небольшим вертикальным сдвигом 2% высоты. Player использует только fade: native video не масштабируется и не участвует в Hero. Back проигрывает обратный переход.

Смена раздела Главная/Избранное даёт короткий fade-in только нового содержимого. CatalogScreen и левое меню остаются смонтированными: ключ анимации принадлежит содержимому, смена источника данных заменяет CatalogBloc и сбрасывает прокрутку карточек. Ширина, непрозрачность и фокус меню не сбрасываются, в том числе при быстрых переключениях. Исходящий каталог не удерживается ради crossfade: это исключает дублирование Hero-тегов, focus и запросов. Подтверждённая сайтом звёздочка плавно появляется/исчезает; это не оптимистическое изменение избранного.

Левое меню раскрывается по фокусу: ширина 88 → 264 logical pixels, подписи проявляются, содержимое за меню затемняется. При уходе фокуса эффект идёт обратно. Используется standard и enterCurve; сетка не перестраивается на промежуточных кадрах. Смена фокуса во время перехода должна приводить к последнему запрошенному состоянию без блокировки ввода.

TvSideSheet открывается с правого края через showTvSideSheet: Offset(1, 0) → Offset.zero с enterCurve и затемнением фона. Закрытие проигрывает ту же анимацию обратно. Этот переход общий для действий избранного, качества и серии. Фокус принадлежит панели всё время её работы; закрытие восстанавливает цель по правилам [TV-взаимодействия](06_tv_interaction.md).

Focus-масштаб, рамка, прокрутка и controls используют durationOf. Эффекты не меняют выбранную серию, статус аккаунта или позицию воспроизведения.

## 5. Доступность и проверки

При disableAnimations или accessibleNavigation durationOf возвращает ноль; HeroMode отключает полёт постера, страницы, разделы и боковые панели переключаются сразу, shimmer заменяется статическим цветом. Видимый focus сохраняется.

Регрессии проверяют промежуточную и конечную ширину меню, сохранение геометрии каталога, выезд панели справа, возврат фокуса, а также Hero из обоих разделов до HTTP, завершение загрузки в середине полёта, обратный переход, быстрый Back, наличие декодированного изображения на каждом кадре при раннем/позднем ответе и оба режима отключения анимаций. Android E2E проверяет focus, избранное, переходы detail/player, native HLS и возврат; статические goldens защищают финальный вид. Перед координатным нажатием Android E2E ждёт завершения анимации панели и доступности цели для hit test; наличия текста в дереве недостаточно. Плавность на физическом TV проверяется отдельно.

Исходники: [AppMotion](../../lib/packages/ui_kit/lib/src/theme/app_palette.dart), [TvPosterHero](../../lib/packages/ui_kit/lib/src/widgets/tv_poster_hero.dart), [AppNavigationPage](../../lib/app/app_navigation_page.dart), [route tests](../../test/app/navigation_motion_test.dart). Результаты: [состояние проверок](../06_verification.md).

Ряд фильтров карточки и экран жанров прокручиваются к фокусу за AppMotion.fast с учётом reduced motion. Открытие результата сохраняет исходный маршрут и фокус; обратный переход возвращает к той же метке. Контракт данных и пульта: [жанры и фильтры](09_catalog_filters.md).

Сортировка жанра использует ту же правую TvSideSheet. При применении старые карточки сразу заменяются skeleton новой первой страницы; crossfade двух выдач не используется. Возврат из панели сохраняет фокус кнопки сортировки, прокрутка строк панели использует AppMotion.fast.

Меню слева и справа, сортировка и фильтры используют общий AppFocusStyle: тёмный фиолетовый градиент, светлая акцентная рамка и мягкая размытая тень. Текст остаётся светлым. Плашки фильтров меняют оформление за AppMotion.fast с учётом reduced motion; свечение не требует backdrop blur. Карточка аниме сохраняет масштабирование, рамку и свечение при фокусе, без дополнительного значка Play поверх постера.

Right в левом меню и Left в правой панели запускают стандартное закрытие с восстановлением фокуса; ввод не ждёт анимации. Кнопки управления player используют общий тёмный фиолетовый стиль выделения меню. Fade controls сохраняет AppMotion.fast; скрытие по idle возвращает focus видео сразу, без ожидания fade. Reduced motion не меняет интервалы seek и idle.

При увеличенном тексте прокрутка к hero-действию использует AppMotion.fast и durationOf; в reduced motion действие становится видимым сразу. Постер при увеличении текста не растёт вместе с высотой hero. Декодирование сетевых изображений ограничивается одной осью по текущей геометрии и DPR, сохраняя пропорции и исходник дискового кеша для крупного detail/Hero. Семейство шрифта темы и тестового bootstrap — packages/ui_kit/Inter из font manifest пакета UI Kit.

Typeset сохраняет длительности, кривые и направления фокуса. Высота фильтров, шапки меню и строк выбора учитывает системный текст до прокрутки; ensureVisible использует прежние fast/durationOf. Таймер player выводится табличными цифрами, чтобы изменение времени не сдвигало текст.

Harden использует fast/durationOf для раскрытия фокуса формы входа и кнопки состояния; reduced motion делает их видимыми без анимации. Переходы ошибки/повтора не добавляют отдельного эффекта и не удерживают старые данные для crossfade. Изменение числа колонок жанров вызвано системным текстом, а не анимацией.

Optimize сохраняет fade controls, focus nodes и native controller. Когда controls скрыты, обновления позиции/буфера сохраняются без перестроения PlayerView; изменения буферизации, ошибки, инициализации и aspect ratio продолжают обновлять экран. Открытие controls сразу использует текущее значение controller. Подписка снимается при его замене и dispose; интервалы idle/seek и reduced motion не меняются.

StartupScreen не задерживает переход после ответа сети ради декоративной анимации. Загрузка обозначена стандартным CircularProgressIndicator и сменой liveRegion-текста; проверка сайта/сессии имеет сетевую длительность, не таймер AppMotion. Ошибка заменяет индикатор сообщением и кнопкой без route-анимации; прокрутка к фокусу повтора использует fast с учётом reduced motion.
