# TV-взаимодействие | AniStar TV

Спецификация задаёт согласованный контракт управления AniStar TV с телевизионного пульта и общие правила focus. Ориентир UX — YouTube для телевизоров; границы адаптации закреплены в [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md). Мобильное поведение описано отдельно в [мобильном взаимодействии](10_mobile_interaction.md).

## 1. Focus и активация

Интерактивная плитка должна быть доступна стрелками пульта и иметь видимый focus, Semantics button/focused и semanticLabel. Touch использует то же действие, что и пульт. Контролируемый экран не должен зависеть от наличия клавиатуры или указателя мыши.

Карточки каталога и избранного, карточки серий и строки выбора серии/качества используют общий визуальный контракт UI Kit для рамки, свечения и переходов фокуса. Карточный вариант умеренно увеличивается; строки выбора сохраняют исходный размер и геометрию. Focus не подменяет состояния выбранного элемента и просмотренной серии: каждое состояние остаётся различимым.

Контур изображения совпадает с внутренней границей рамки с учётом её толщины. Изображение и заглушка используют одинаковую геометрию. Переход Hero сохраняет скруглённую форму на исходном и целевом концах. Увеличение не обрезает рамку и не перекрывает соседние элементы.

TvFocusable принимает Enter, Select/OK, Space и gameButtonA. Первый KeyRepeat распознаёт удержание; последующие повторы не повторяют действие.

| Вход | Поведение |
| --- | --- |
| KeyDown без long action | Однократный onPressed |
| KeyDown при наличии long action | Запомнить клавишу, без таймера и немедленного открытия |
| KeyUp той же клавиши без KeyRepeat | onPressed |
| Первый KeyRepeat удерживаемой клавиши | Немедленно onLongPressed, ещё до отпускания |
| Потеря focus или dispose до release | Отменить ещё не распознанное удержание; ничего не открыть |
| Touch tap | Установить focus, вызвать onPressed |
| Touch long press | Установить focus, вызвать onLongPressed без короткого действия |

Длинное действие вызывается при системном KeyRepeat. Задержку определяет устройство, фиксированного порога в три секунды нет. Устройства без repeat не распознают долгое OK; touch использует штатный onLongPress. Остаток распознанного удержания (повторы и KeyUp) поглощается до передачи фокусу, чтобы не нажать первую кнопку новой панели. Нельзя одновременно открыть detail и выполнить favorite action.

## 2. Каталог и боковые панели

Каталог, избранное, жанры и карточка аниме используют TV-компоновку с постоянным левым меню. Маршруты жанров и полной карточки сохраняют выбранный раздел меню и цель возврата. Они не создают ещё один каталог или запрос каталога ради меню. Игрок и вход остаются отдельными экранами. Каталог не имеет верхних вкладок и toolbar. Шапка TvHeaderSurface остаётся в полной карточке; название показывается в содержимом один раз.

Экран входа и шапка левого меню используют общий AnistarLogo из UI Kit, с прозрачным PNG `anistar_logo.png`. Иконка запуска использует отдельный PNG с фоном. Логотип декоративный рядом с названием приложения, не получает фокус и не добавляет пункт в обход крестовиной.

Левое меню без фокуса показывает иконки. При фокусе оно показывает иконки и подписи. В раскрытом меню видны название приложения и логин подтверждённого аккаунта. Порядок пунктов: Главная → Избранное → Жанры → Выйти из аккаунта → Логи. Меню пропускает недоступные действия. В release логов нет.

Отдельной команды обновления каталога нет. При ошибке загрузки доступно действие повтора.

Выбранный раздел остаётся выделенным без фокуса. Сфокусированный пункт использует общий стиль UI Kit по [визуальной системе](11_visual_system.md); выбранное состояние остаётся различимым от фокуса.

| Контекст | Клавиша | Поведение |
| --- | --- | --- |
| Первая карточка любого ряда | Left | Фокус текущего раздела в левом меню |
| Меню | Up / Down | Предыдущий / следующий доступный пункт; на краю остановка |
| Меню | OK | Открыть раздел или выполнить выбранное действие |
| Меню | Right | Вернуть последнюю доступную карточку либо действие содержимого |
| Раскрытое меню | Back | Свернуть меню и вернуть фокус содержимому |
| Первый ряд карточек | Up | В каталоге выбранного фильтра — кнопка сортировки; на главной/в избранном — остаться в сетке |
| Правая граница ряда | Right | Остаться на карточке |

При первом открытии загруженного каталога фокус получает первая карточка. После выбора раздела фокус остаётся на его пункте меню, включая пустое избранное. Смена Главная/Избранное заменяет только содержимое. Левое меню, его FocusNode, прокрутка списка пунктов и текущее раскрытие сохраняются. Открытие жанров и полной карточки сохраняет выбранный пункт меню. Back возвращает к прежнему содержимому и его доступной цели focus.

Right переводит фокус к карточкам или кнопке «Перейти на главную». После удаления последней карточки избранного фокус возвращается в меню. При ошибке загрузки фокус переходит на кнопку повтора. Навигация по пунктам без OK не меняет раздел и не выполняет действия.

Если при явном переходе Right в раздел жанров данные ещё загружаются, focus сохраняется в области содержимого. После загрузки он переходит на первую доступную плитку. Для пустого списка или ошибки целью становится действие повтора. Отложенный callback проверяет, что пользователь всё ещё находится в этом содержимом. Он не перехватывает focus после возврата в меню, смены раздела, открытия другого маршрута или dispose экрана.

Меню занимает 88 logical pixels в свёрнутом состоянии и раскрывается до 264 поверх края каталога. Содержимое затемняется. Касание затемнения возвращает фокус содержимому. Раскрытие не меняет геометрию сетки.

Возврат из detail сохраняет выбранную карточку. Фокус карточки прокручивает её в видимую область. Дозагрузка возможна только из Ready с hasMore. Она может начаться при extentAfter <500 logical pixels или когда фокус находится в последних двух рядах. Защита запросов и retry описаны в [пагинации](03_page_loading.md).

CatalogLayout использует ширину области сетки после места, отведённого левому меню: 2 колонки при ширине меньше 600, 3 при ширине от 600, 4 от 820 и 5 от 1352 logical pixels. Поэтому эталон TV 1280×720 сохраняет 4 колонки, а область сетки в окне шириной 1440 pixels допускает 5. Native TV 960×540 также использует 4 колонки. Loading использует ту же геометрию. Отдельные заголовок «Каталог», счётчик загруженных карточек и постоянные подсказки про OK отсутствуют.

Долгое нажатие OK или долгое касание открывает FavoriteActionsSheet через общий showTvSideSheet. Панель выезжает справа. Её ширина — до 440 logical pixels, высота — вся доступная высота. Фон затемняется, а фокус остаётся внутри панели.

Left, Back, наружное касание или «Закрыть» закрывают панель. Доступный исходный элемент снова получает фокус. Закрытие панели во время запроса не отменяет уже отправленное изменение сайта.

Панель сначала читает свежий статус, показывает loading, затем одно определённое действие. Ошибка предлагает «Обновить статус» и фокусирует его: OK повторяет чтение. Во время mutation повторное изменение недоступно. Само открытие панели не изменяет избранное.

В карточке сериала focus начинается на основном действии. Оно предлагает доступную серию с наименьшим номером строго выше максимального номера, отмеченного сайтом. Если отметок нет, действие предлагает первую доступную серию. Если следующей серии нет, «Посмотреть снова» предлагает первую доступную. Если запускать нечего, действие отключено. Локальная история плеера это правило не меняет. Если серий нет, focus начинается на избранном. Left/Right переключают эти действия. Down с любого действия ведёт к первой плитке сетки. Up из первого ряда возвращает focus к основному действию и прокручивает scroll view к началу.

Список серий содержит ровно три колонки на всех поддерживаемых размерах TV, в состояниях loading и ready. Пульт следует этой сетке: focus не выходит за края ряда и не попадает в пустую ячейку неполного последнего ряда. Все доступные серии остаются в списке. При увеличении текста карточки растут по высоте, а длинный список прокручивается; шрифт не уменьшается ради трёх колонок. Выбор открывает сфокусированную серию. После возврата из player сохраняются её focus и положение прокрутки. Если выбранной серии больше нет, focus получает доступная цель по действующему контракту. Загрузка не получает focus, а пустой список и ошибка сохраняют действия восстановления.

Up с действий ведёт к ряду меток категорий/жанров. Следующий Up ведёт к кнопке возврата в AppBar. Down с возврата ведёт к меткам, затем к основному действию. Если кликабельных меток нет, focus переходит напрямую между действиями и возвратом. Подробные правила и переходы из левого меню описаны в [жанрах и фильтрах](09_catalog_filters.md).

После ухода в player и возврата маршрут сохраняет focus выбранной серии. В длинной сетке каждая сфокусированная серия прокручивается в видимую область.

После смены параметров detail/route данные загружаются заново; старый Future не определяет содержимое нового экрана. Выход и смена origin закрывают protected navigation и панели предыдущего аккаунта.

## 3. Управление player

После native pause или завершения серии controls появляются и остаются видимыми. Это правило действует и для остановки без нажатия кнопки в приложении. Существующий controller сохраняется; дополнительные HTTP-запросы не нужны.

Команды воспроизведения требуют существующего controller. При фокусе самого видео действует таблица ниже; кнопки и шкала имеют отдельные правила. Открытая панель выбора не должна передавать команды фоновому player.

| Клавиша | Действие |
| --- | --- |
| OK / Enter / Space / mediaPlayPause / gameButtonA | Play/pause |
| mediaPlay | Воспроизвести; повторная команда не ставит на паузу |
| mediaPause | Приостановить; повторная команда не запускает видео |
| Left / Right | Создать черновую цель −10 / +10 секунд; применить одну конечную цель после KeyUp активного направления |
| Up | Показать меню и перевести focus на «К сериям» |
| Down | Показать меню и перевести focus на кнопку Play/pause |
| Back | Закрыть player и освободить native ресурсы |

Возврат к сериям расположен сверху слева. Над нижним рядом кнопок проходит шкала времени с текущей и буферизованной позицией; ниже видны время / длительность. В нижнем ряду слева направо: Play/pause → −10 секунд → +10 секунд → Предыдущая серия → Следующая серия → Серии → Качество. Недоступные действия не выводятся. Полноэкранной кнопки нет; постоянные инструкции про клавиши отсутствуют. Иконки имеют семантические имена и tooltip.

После успешной инициализации native player кнопка показывает SD для `selectedQuality` 360p и HD для 720p. До этого `requestedQuality` не служит подтверждением качества. Подробности подтверждения и восстановления описаны в [контракте воспроизведения](04_playback.md).

Активация пультом или касанием открывает существующую правую панель. Она показывает только доступные качества с подписями «SD 360p» и «HD 720p»; текущий вариант отмечен и получает начальный focus. Даже при одном доступном варианте панель открывается. Отмена и выбор текущего качества не открывают источник повторно. После закрытия панели focus возвращается к видео; сама панель не передаёт ему команды.

На кнопках Left/Right перемещают фокус внутри ряда без seek. Down с возврата ведёт на шкалу, затем в нижний ряд; Up из ряда возвращает на шкалу, затем к возврату. После шкалы фокус возвращается к запомненной кнопке ряда. Up с возврата или Down из нижнего ряда возвращает фокус самому видео.

На шкале Left/Right меняют черновую цель так же, как на видео; касание шкалы сохраняет прямой seek. Фокус шкалы заметен по толщине линии и размеру бегунка. OK на кнопке выполняет только её действие.

Play/pause обрабатывается на KeyDown. KeyRepeat не повторяет эту команду. Перемещение по меню допускает repeat. На видео и шкале KeyDown Left/Right меняет только черновую цель на 10 секунд. Native seek не вызывается до KeyUp активного направления. Повтор чернового шага начинается через 500 мс и продолжается каждые 500 мс; скорость шага зависит от длительности текущего удержания. Системный KeyRepeat не добавляет шагов. Границы скорости, продолжение черновика при смене направления и правила очереди описаны в [контракте воспроизведения](04_playback.md#перемотка-и-controls).

KeyUp текущего направления применяет одну конечную цель. KeyUp прежнего направления после смены направления игнорируется. Уход фокуса со шкалы или видео отменяет черновик. Его также отменяют другая команда, панель, смена источника или controller, переход в фон, ошибка, Back и dispose. При отмене UI возвращается к актуальной позиции. Поздние события прежнего controller не меняют новый поток.

Timer скрытия срабатывает после 4 секунд бездействия во время воспроизведения. Он действует независимо от фокуса кнопок и шкалы. KeyDown/KeyRepeat, изменение фокуса, касание и seek обновляют timer. Позиционные события воспроизведения его не продлевают.

Во время удержания seek controls остаются видимыми, в том числе на границе видео. После отпускания отсчитываются новые 4 секунды. На паузе, при завершении и в панели выбора controls не скрываются.

При скрытии focus получает само видео. Следующее Up/Down показывает управление и переводит focus на Back/Play после layout. Скрытые controls исключены из focus. Play/Pause/PlayPause с media-кнопок работают также при focus кнопок меню. Во время панели эти команды не управляют фоновым player.

Серии в карточке аниме и панели player упорядочены по числовому номеру от последней к первой. В сетке чтение идёт слева направо, затем вниз. Номер серии выводится один раз в видимой подписи и один раз в её семантической подписи. Если полное название после нормализации регистра и пробелов совпадает с «Серия N», повтор этого названия не показывается. Собственное описательное название сохраняется; произвольные части названия не удаляются. Отметка просмотра остаётся отдельной от текущего выбора. Основная кнопка выбирает минимальную доступную серию с номером выше максимальной подтверждённой отметки сайта; без отметок выбирает минимальную доступную. Ранние пропуски остаются ручным выбором. Если следующей доступной серии нет, «Посмотреть снова» запускает первую доступную. Новая формула и поведение карточки принадлежат [спецификации карточки аниме](12_anime_details.md). После обновления истории текст и действие меняются вместе, фокус сохраняется.

Порядок частей и действие полной карточки описаны в [спецификации карточки аниме](12_anime_details.md). Панель серий сразу показывает текущую серию и переводит focus на неё, даже если она далеко от начала списка. Up/Down прокручивают выбранную строку в видимую область. Выбор того же качества/серии или отмена панели не перезагружают поток. После закрытия chooser focus возвращается видео. Следующее OK меняет play/pause, Left/Right выполняют seek.

После окончательного отказа запуска или прерывания focus получает «Повторить». OK делает один ручной retry с новым бюджетом. После восстановления focus возвращается управлению видео. Поздний выбор от уже закрытой initialization игнорируется.

Player использует immersiveSticky. При dispose он возвращает manual system UI без overlays, как ожидает TV-приложение. Не оставлять timers, listeners или focus nodes после ухода. Сохранение позиции при качестве и сброс при серии задаёт [playback](04_playback.md).

<a id="5-загрузка-и-визуальные-состояния"></a>
## 4. Загрузка и визуальные состояния

Каталог показывает скелетоны постеров с теми же отступами и сеткой, что загруженная страница; левое меню остаётся доступным. Карточка сериала показывает отдельные формы постера, текста и кнопки; высота hero и три колонки серий общие для loading и ready. Загрузка не получает focus.

Один skeleton-контейнер управляет shimmer всех своих форм; вложенные изображения используют его, не создавая дополнительные анимации. При системном отключении анимации формы остаются видимыми без shimmer. Заглушки исключены из Semantics и не принимают focus.

Длинные названия и метаданные ограничены строками с ellipsis. Число строк описания вычисляется по доступной высоте над кнопками и масштабу текста; последняя видимая строка получает многоточие. Фоновой картинке hero не показывают error icon, чтобы он не перекрывал текст. Вход оформлен общей темой; кнопка видимости пароля доступна пультом и касанием.

На 960×540 и 1280×720 golden-регрессии каталога, меню, панелей, плеера, входа, загрузки и длинной карточки сохраняют компоновку без overflow. Golden baselines закреплены за SDK и локальными шрифтами, сравнение точное. Изменение baselines требует просмотра PNG; генерация не заменяет проверку пультом и Android E2E.

<a id="6-вход-с-пульта"></a>
## 5. Вход с пульта

Если подтверждённой сессии нет, начальный focus экрана входа получает логин. Действие «Далее» экранной клавиатуры переводит focus в пароль, «Готово» отправляет форму. После типизированного отказа из-за неверных учётных данных пароль очищается и снова получает focus; при транспортной или серверной ошибке оба поля сохраняют ввод. Подробное правило находится в [спецификации входа](01_authentication.md).

При закрытой экранной клавиатуре Down переводит логин → пароль → «Войти», Up переводит «Войти» → пароль → логин. KeyDown и KeyRepeat используют одинаковый явный порядок; Up на логине остаётся в логине. Down с «Войти» остаётся на отправке; проверка сохранённой сессии находится на отдельном стартовом экране.

Однострочные поля не перехватывают Up/Down как движение курсора. Left/Right остаются доступны для редактирования текста. Поля отключены только на время запроса. Focus nodes освобождаются вместе с экраном.

Регрессии проверяют позднюю серию 20 из 24, переход до последней стрелками и OK, отмену панели, возврат к той же карточке, пустое избранное и повтор после ошибки избранного. Android E2E дополняет widget-проверки переходами пультом и native playback. Экранная клавиатура и раскладка кнопок конкретного физического TV остаются отдельной ручной проверкой.

В эмуляторе отдельно проверяется `Extended Controls → Directional Pad`: Flutter `sendKeyEvent` и Android `input keyevent` обходят kernel keyboard device. E2E preflight требует hardware input с четырьмя стрелками; локальному API 36 TV-профилю нужны `hw.dPad=yes` и `hw.keyboard=yes` с Cold Boot после изменения. Инструкция находится в [разработке и тестировании](../05_development_and_testing.md#directional-pad-эмулятора).

На корне главной системный Back открывает подтверждение «Выйти из приложения?» с действиями «Остаться» и «Выйти». Начальный фокус получает «Остаться». Отмена восстанавливает исходный контекст. Подтверждение закрывает Android-приложение штатным платформенным способом и сохраняет аккаунт; logout выполняется отдельно. Логотип не запускает закрытие приложения. На iOS программное завершение не добавляется.

Каталог выбранного жанра, года или режиссёра показывает текущую сортировку у названия. Правая панель выбора, черновик/применение, управление пультом и возврат фокуса описаны в [контракте сортировки](09_catalog_filters.md#6-сортировка-фокус-отмена-и-восстановление).

Кнопки предыдущей и следующей серии выбирают ближайший доступный номер ниже/выше текущего, включая пропуски в нумерации. На границе списка недоступная кнопка скрыта и исключена из фокуса. Переключение использует обычную смену серии: позиция сбрасывается, качество сохраняется, прежний native controller освобождается. Кнопки player используют общие визуальные роли из спецификации 11. Left в правой панели закрывает её без применения черновика и восстанавливает исходный фокус (в player — фокус видео). Right в левом меню сворачивает его, возвращая последнюю доступную карточку или действие содержимого.

## Масштаб текста и доступность ошибок

Основной шрифт и семантические типографические роли заданы [визуальной системой](11_visual_system.md). Платформенные размеры учитывают системный масштаб текста.

| Роль TV | Размер до → после | Основа темы |
| --- | ---: | --- |
| Название карточки каталога/избранного | 16 → 15 | `titleSmall` |
| Год карточки каталога/избранного | 16 → 15 | `labelLarge` |
| Заголовок карточки сериала, широкая область | 32 → 30 | `headlineLarge` |
| Заголовок карточки сериала, узкая область | 28 → 26 | `headlineMedium` |
| Описание | 18 → 17 | `bodyLarge` |
| Название серии | 19 → 18 | `titleMedium` |
| Подпись серии | 14, без изменения | `labelMedium` |
| Заголовок секции | 24, без изменения | `headlineSmall` |

Шкала применяется к названным поверхностям без глобального масштабирования темы. Сохраняются типографическая иерархия, системный `textScaler` и размеры областей касания; визуальные роли принадлежат спецификации 11. Описание ограничено шириной 720 logical pixels. Измерение высоты карточки серии использует те же роли подписи и названия, что и готовая карточка. Таймер player использует табличные цифры.

Высота фильтров не меньше 48 и растёт по масштабированному тексту с отступами. Виртуализированные строки выбора используют TvChoiceTile.rowExtentOf: 64 при обычном тексте, больше при увеличении. Шапка меню растёт по тексту; длинные подписи допускают две строки при увеличении, имя аккаунта сохраняет ellipsis. Фокус и выбранная серия остаются видимыми после D-pad-переходов; Left/Right/OK и возврат фокуса сохраняют прежний контракт.

При увеличенном системном тексте hero карточки сериала имеет общую со skeleton минимальную высоту, учитывающую масштаб, и растёт дальше по содержимому. Постер сохраняет базовую геометрию; текст не сжимается ради кнопок. Начальный фокус на «Смотреть»/избранном и возврат Up из серий прокручивают выбранное действие в видимую область. При обычном масштабе сохраняется возврат к началу страницы. Направления пульта и действия OK не меняются. Проверяются 130% и 200% в 960×540, 1280×720 и узком landscape 640×360.

Ошибка входа доступна как Semantics liveRegion: новое сообщение объявляется средствами TalkBack, а focus после отказа остаётся на поле повторного ввода пароля. Сообщение не озвучивается отдельным дублирующим вызовом announce.

## Устойчивость состояний интерфейса

Общие цвета, состояния, роли текста и фокусная рамка задаются [визуальной системой](11_visual_system.md). Hover/focus/pressed остаются различимыми, а контраст текста относительно фона сохраняется. Размеры областей управления и порядок пульта остаются частью этого TV-контракта.

TvStateView сохраняет центрирование обычного состояния и прокручивает длинное содержимое. Заголовок с сообщением имеет общий Semantics liveRegion; фокус кнопки повтора раскрывает её в видимую область. Ошибка дозагрузки каталога сохраняет карточки, ограничивает текст доступной высотой и оставляет повтор по OK. Пустой список серий предлагает «Обновить серии»; Down с избранного достигает этого действия, успешный повтор возвращает доступные выпуски.

Форма входа допускает перенос бренда и надписи загрузки, раскрывает логин/пароль/отправку при фокусе, включая увеличенный текст и экранную клавиатуру. Повторная отправка во время входа игнорируется. При неверных учётных данных сохраняется логин, очищается пароль и фокус возвращается в пароль; при сетевой или серверной ошибке оба поля сохраняются. Подробное правило находится в [спецификации входа](01_authentication.md).

Жанры учитывают масштаб и в числе колонок, и в высоте двух строк. При 200% на узком телефоне список становится одноколоночным. Полная метка доступна в semantics, даже при ellipsis. Пульт сохраняет порядок по строкам и выбор только по OK.

Anime/genres/player показывают безопасное message известного Failure; неожиданное исключение заменяется сообщением с доступным повтором. Обработчик ошибки маршрута не выводит URI/параметры и не записывает их в лог; «На главную» восстанавливает каталог. Поздний ответ прежнего anime-запроса не меняет подтверждённое избранное после смены параметров карточки.

## Стартовый экран

StartupScreen показывает логотип и статус проверки доступности сайта, затем сохранённой сессии. Полей ввода и интерактивных пунктов во время проверки нет. Форма входа и protected router закрыты до результата; Back не открывает их в обход проверки.

На ошибке начальный фокус получает «Попробовать снова», OK делает один повтор. После нажатия кнопка и прежняя ошибка скрываются до результата, повторный OK не создаёт параллельную операцию. Длинное сообщение прокручивается, фокус раскрывает кнопку в видимую область. Статус и ошибка объявляются как liveRegion.

Гость или истёкшая сессия переходят на форму с фокусом на логине; подтверждённая сессия — на главную с существующим начальным фокусом каталога. Ошибка отправки логина остаётся в форме и переводит фокус в пароль. Golden-регрессии стартовых этапов и ошибки фиксируют 960×540, 1280×720 и portrait 390×844 при 200% текста; widget-тесты проверяют этапы, gate и повтор с пульта, Android fixture E2E — отказ restore и восстановление без нового login POST.

Карточки каталога и избранного используют общую геометрию и семантические роли из спецификации 11. Сердце обозначает подтверждённое избранное, звезда — рейтинг; метки не получают отдельный фокус или действие. Рейтинг показывается с одной цифрой после запятой без знаменателя, например `★ 8,7`; семантическая подпись — «Рейтинг 8,7 из 10». Отсутствующее или некорректное значение не показывается как ноль. Переходы крестовиной и OK остаются прежними. Фон карточки сериала доходит до боковых границ SafeArea без дополнительного минимального отступа; внутренние отступы текста и действий сохраняются.
