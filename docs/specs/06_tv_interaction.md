# TV-взаимодействие | AniStar TV

Спецификация задаёт согласованный контракт управления AniStar TV с телевизионного пульта и общие правила focus. Ориентир UX — YouTube для телевизоров; границы адаптации закреплены в [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md). Мобильное поведение описано отдельно в [мобильном взаимодействии](10_mobile_interaction.md).

## Термины и ответственность

- **Термины:** [аниме, каталог и поиск](../01_01_domain_glossary.md#2-аниме-каталог-и-поиск); [избранное и просмотр](../01_01_domain_glossary.md#3-избранное-и-просмотр).
- **Ответственность:** распределена между [фичами](../01_02_feature_responsibilities.md#1-владельцы-поведения) и [UI Kit / app](../01_02_feature_responsibilities.md#2-композиция-и-инфраструктура).
- **Участники:** UI Kit предоставляет общие focus-компоненты; home — оболочку; экраны фич — свои маршруты фокуса и действия; app — переходы между экранами.

## 1. Focus и активация

Интерактивная плитка должна быть доступна стрелками пульта и иметь видимый focus, Semantics button/focused и semanticLabel. Touch использует то же действие, что и пульт. Контролируемый экран не должен зависеть от наличия клавиатуры или указателя мыши.

Карточки каталога и избранного, карточки серий и строки выбора серии/качества используют общий визуальный контракт UI Kit для рамки, свечения и переходов фокуса. Карточный вариант умеренно увеличивается; строки выбора сохраняют исходный размер и геометрию. Focus не подменяет состояния выбранного элемента и просмотренной серии: каждое состояние остаётся различимым.

Контур изображения совпадает с внутренней границей рамки. Изображение и заглушка имеют одинаковую геометрию. Увеличение сохраняет видимость рамки и соседних элементов.

TvFocusable принимает Enter, Select/OK, Space и gameButtonA. Первый KeyRepeat распознаёт удержание; последующие повторы не повторяют действие.

| Вход | Поведение |
| --- | --- |
| KeyDown без long action | Однократный onPressed |
| KeyDown при наличии long action | Запомнить клавишу, без таймера и немедленного открытия |
| KeyUp той же клавиши без KeyRepeat | onPressed |
| Первый KeyRepeat удерживаемой клавиши | Немедленно onLongPressed, ещё до отпускания |
| Потеря focus или dispose до release | Отменить ещё не распознанное удержание; ничего не открыть |
| Touch tap | Установить focus, вызвать onPressed |
| Touch long press | Установить focus, вызвать onLongPressed без короткого действия |

Длинное действие вызывается при системном KeyRepeat. Задержку определяет устройство, фиксированного порога в три секунды нет. Устройства без repeat не распознают долгое OK; touch использует штатный onLongPress. Остаток распознанного удержания (повторы и KeyUp) поглощается до передачи фокусу, чтобы не нажать первую кнопку новой панели. Нельзя одновременно открыть detail и выполнить favorite action.

## 2. Каталог и боковые панели

Каталог, избранное, жанры, фильтрованные выдачи и карточка аниме используют одну TV-оболочку с постоянным левым меню. При переходах экземпляр меню и его узлы фокуса сохраняются. Маршруты сохраняют выбранный раздел, параметры и цель возврата. Они не создают ещё один каталог или запрос каталога ради меню. Плеер остаётся полноэкранным, вход — отдельным экраном. Каталог не имеет верхних вкладок и toolbar. Шапка TvHeaderSurface остаётся в полной карточке; название показывается в содержимом один раз.

Экран входа и шапка левого меню используют общий AnistarLogo из UI Kit, с прозрачным PNG `anistar_logo.png`. Иконка запуска использует отдельный PNG с фоном. Логотип декоративный рядом с названием приложения, не получает фокус и не добавляет пункт в обход крестовиной.

Левое меню без фокуса показывает иконки. При фокусе оно показывает иконки и подписи. В раскрытом меню видны название приложения и имя подтверждённого аккаунта. Подтверждённое личное изображение показывается по URI; при стандартном аватаре, отсутствии метаданных, загрузке или ошибке показываются инициалы. Получение, проверку, доставку и изоляцию профиля определяет [спецификация входа](01_authentication.md#старт-и-экран-входа). Порядок и доступность пунктов зависят от состояния доступа: аккаунт видит Главную, Поиск, Избранное, Жанры, имя аккаунта и выход; гость — Главную, Поиск, Жанры и вход. Логи доступны только при поддержке приложения. Гостю не показывают аватар, выход и Избранное. В release логов нет.

Отдельной команды обновления каталога нет. При ошибке загрузки доступно действие повтора.

Выбранный раздел остаётся выделенным без фокуса. Сфокусированный пункт использует общий стиль UI Kit по [визуальной системе](11_visual_system.md); выбранное состояние остаётся различимым от фокуса.

| Контекст | Клавиша | Поведение |
| --- | --- | --- |
| Карточка внутри ряда | Left | Перейти к соседней карточке слева |
| Первая карточка ряда | Left | Перейти к активному пункту левого меню |
| Меню | Up / Down | Предыдущий / следующий доступный пункт; на краю остановка |
| Меню | OK | Открыть другой раздел, свернуть меню и передать фокус по правилам выбранного раздела. Повторный выбор текущего раздела возвращает последнюю доступную цель содержимого |
| Меню | Right | Вернуть последнюю доступную карточку либо действие содержимого |
| Раскрытое меню на неглавном разделе | Back | Перейти на Главную; на Главной открыть подтверждение закрытия приложения |
| Постер ленты | Up | Перейти к «Смотреть», синхронизировав выбранный тайтл |
| Постер ленты | Right | Перейти к следующему доступному постеру |

При выборе другого раздела по OK обычный каталог передаёт фокус выбранной доступной карточке, поиск — полю ввода. При первом открытии «Жанров» фокус получает первая плитка. При возвращении в «Жанры» фокус получает последний сфокусированный жанр, если он ещё есть в списке, иначе — первая плитка. При пустом списке или ошибке фокус получает «Повторить». Смена Главная/Избранное переключает видимое содержимое, сохраняя посещённые экраны. Левое меню, его FocusNode и прокрутка списка пунктов сохраняются. Открытие жанров и полной карточки сохраняет выбранный пункт меню. Back возвращает к прежнему содержимому и его доступной цели focus.

Right переводит фокус к карточкам или кнопке «Перейти на главную». После удаления последней карточки избранного фокус возвращается в меню. При ошибке загрузки фокус переходит на кнопку повтора. Навигация стрелками по пунктам без OK меняет только фокус и не выполняет действие. Back из корневого содержимого раскрывает меню на активном разделе. Навигация и оболочка TV сохраняются при смене состояния доступа.

Если при явном переходе Right в раздел жанров данные ещё загружаются, focus сохраняется в области содержимого. После загрузки фокус переходит к плитке или действию повтора по тем же правилам. Отложенный callback проверяет, что пользователь всё ещё находится в этом содержимом. Он не перехватывает focus после возврата в меню, смены раздела, открытия другого маршрута или dispose экрана.

Меню занимает 72–88 logical pixels в свёрнутом состоянии и раскрывается до 216–264 поверх края каталога. На 960×540 это 72 и 216, на 1280×720 — 88 и 264. Содержимое затемняется. Касание затемнения возвращает фокус содержимому. Раскрытие не меняет геометрию ленты.

Возврат из detail или прямого запуска сохраняет источник, выбранный постер и позицию ленты. У поиска сохраняются запрос и черновик без повторного открытия IME. Появление первого незагруженного слота в viewport запускает допустимую дозагрузку; состояние запроса и retry описаны в [пагинации](03_page_loading.md).

Главная, избранное, поиск и непустая фильтрованная выдача используют общую горизонтальную ленту и сведения над ней. Постеры 2:3 движутся к левому якорю; фокус и цель прокрутки меняются сразу, сведения и фон — после задержки. Переход к действиям сразу синхронизирует выбранный тайтл. Заголовок ленты отражает источник. Down с действий возвращает к постеру; Right с «Смотреть» ведёт к доступному избранному, затем к сортировке. Up с действий ведёт к жанрам или сортировке, а в поиске без этих целей — к форме. Жанры перемещаются по соседям и визуальным строкам. Плитки выбора жанров сохраняют отдельную сетку.

Долгое нажатие OK или долгое касание открывает FavoriteActionsSheet через `showAppActionSheet`, который на TV использует `showTvSideSheet`. Панель выезжает справа. Её ширина — до 440 logical pixels, высота — вся доступная высота. Фон затемняется, а фокус остаётся внутри панели.

Left, Back, наружное касание или «Закрыть» закрывают панель. Доступный исходный элемент снова получает фокус. Закрытие панели во время запроса не отменяет уже отправленное изменение сайта.

Для подтверждённого аккаунта панель читает свежий статус, показывает loading, затем одно определённое действие. Ошибка предлагает «Обновить статус» и фокусирует его: OK повторяет чтение. Во время mutation повторное изменение недоступно. Гость получает действие «Войти, чтобы добавить в избранное». Само открытие панели не изменяет избранное. Прямые кнопки панели занимают высоту текста и отступов; прокручиваемые списки и содержимое с ограниченной высотой могут растягиваться внутри панели.

Полная карточка открывается и закрывается без анимации маршрута по [общим правилам движения](08_motion.md#3-переход-к-карточке-аниме). После общей успешной загрузки начальный фокус получает серия с максимальным доступным номером, если пользователь ещё не выбрал другую цель. При отсутствии серий доступно восстановление. «Подробнее» раскрывает сведения; первый Back сворачивает их и возвращает фокус на эту кнопку, следующий возвращает к источнику. На TV экранной стрелки Back нет. Кнопки просмотра на полной карточке нет: OK на серии запускает её.

Список серий содержит ровно три колонки на всех поддерживаемых размерах TV, в состояниях loading и ready. Пульт следует этой сетке: focus не выходит за края ряда и не попадает в пустую ячейку неполного последнего ряда. Все доступные серии остаются в списке. При увеличении текста карточки растут по высоте, а длинный список прокручивается; шрифт не уменьшается ради трёх колонок. Выбор открывает сфокусированную серию. После возврата из player сохраняются её focus и положение прокрутки. Если выбранной серии больше нет, focus получает доступная цель по действующему контракту. Загрузка не получает focus, а пустой список и ошибка сохраняют действия восстановления.

Up с первой строки серий ведёт к связанным частям или открытым фильтрам, а при свёрнутых сведениях — к «Подробнее». Down с действий ведёт к открытым фильтрам или сериям. Подробные переходы и возврат описаны в [карточке аниме](12_anime_details.md).

После ухода в player и возврата маршрут сохраняет focus выбранной серии. В длинной сетке каждая сфокусированная серия прокручивается в видимую область.

После смены параметров detail/route данные загружаются заново; старый Future не определяет содержимое нового экрана. Выход и смена origin закрывают protected navigation и панели предыдущего аккаунта.


## Поиск и редактирование с пульта

Поиск является отдельным разделом в TV-меню. При переходе из другого раздела приложение включает редактирование и запрашивает системную IME. Возврат из карточки и повторный выбор уже активного поиска восстанавливают контекст без повторного запроса IME. Порядок целей в поиске: поле → очистка, если она доступна → «Найти» → история и результаты. Пустой крестик очистки пропускается. Завершение запроса не переносит фокус; пустая выдача и ошибка имеют разные сообщения, а ошибка следующей страницы сохраняет карточки и предлагает повтор.

При входе в поиск поле сразу получает focus и режим редактирования. Left/Right и клавиатурный ввод редактируют текст; первый Back завершает редактирование и скрывает IME, затем Left раскрывает меню на «Поиск». Сам ввод не отправляет запрос. Стрелки вверх/вниз в меню только перемещают фокус; OK выбирает раздел. Возврат из карточки сохраняет запрос, выдачу, прокрутку и выбранный постер без повторной отправки и открытия IME. Мобильный профиль использует сенсорное управление и не наследует TV-граф D-pad.

## 3. Управление player

После native pause или завершения серии controls появляются и остаются видимыми. Это правило действует и для остановки без нажатия кнопки в приложении. Существующий controller сохраняется; дополнительные HTTP-запросы не нужны.

Команды воспроизведения требуют существующего controller. При фокусе самого видео действует таблица ниже; кнопки и шкала имеют отдельные правила. Открытая панель выбора не должна передавать команды фоновому player.

| Клавиша | Действие |
| --- | --- |
| OK / Enter / Space / mediaPlayPause / gameButtonA | Play/pause |
| mediaPlay | Воспроизвести; повторная команда не ставит на паузу |
| mediaPause | Приостановить; повторная команда не запускает видео |
| Left / Right | Создать черновую цель −10 / +10 секунд; применить одну конечную цель после KeyUp активного направления |
| Up | Показать меню и перевести focus на «К сериям» |
| Down | Показать меню и перевести focus на кнопку Play/pause |
| Back | Закрыть player и освободить native ресурсы |

Возврат к сериям расположен сверху слева. Над нижним рядом кнопок проходит шкала времени с текущей и буферизованной позицией; ниже видны время / длительность. В нижнем ряду слева направо: Play/pause → −10 секунд → +10 секунд → Предыдущая серия → Следующая серия → Серии → Качество. Недоступные действия не выводятся. Полноэкранной кнопки нет; постоянные инструкции про клавиши отсутствуют. Иконки имеют семантические имена и tooltip.

После успешной инициализации native player кнопка показывает SD для `selectedQuality` 360p и HD для 720p. До этого `requestedQuality` не служит подтверждением качества. Подробности подтверждения и восстановления описаны в [контракте воспроизведения](04_playback.md).

Активация пультом или касанием открывает существующую правую панель. Она показывает только доступные качества с подписями «SD 360p» и «HD 720p»; текущий вариант отмечен и получает начальный focus. Даже при одном доступном варианте панель открывается. Отмена и выбор текущего качества не открывают источник повторно. После закрытия панели focus возвращается к видео; сама панель не передаёт ему команды.

На кнопках Left/Right перемещают фокус внутри ряда без seek. Down с возврата ведёт на шкалу, затем в нижний ряд; Up из ряда возвращает на шкалу, затем к возврату. После шкалы фокус возвращается к запомненной кнопке ряда. Up с возврата или Down из нижнего ряда возвращает фокус самому видео.

На шкале Left/Right меняют черновую цель так же, как на видео; касание шкалы сохраняет прямой seek. Фокус шкалы заметен по толщине линии и размеру бегунка. OK на кнопке выполняет только её действие.

Play/pause обрабатывается на KeyDown. KeyRepeat не повторяет эту команду. Перемещение по меню допускает repeat. На видео и шкале KeyDown Left/Right меняет только черновую цель на 10 секунд. Native seek не вызывается до KeyUp активного направления. Повтор чернового шага начинается через 500 мс и продолжается каждые 500 мс; скорость шага зависит от длительности текущего удержания. Системный KeyRepeat не добавляет шагов. Границы скорости, продолжение черновика при смене направления и правила очереди описаны в [контракте воспроизведения](04_playback.md#перемотка-и-controls).

KeyUp текущего направления применяет одну конечную цель. KeyUp прежнего направления после смены направления игнорируется. Уход фокуса со шкалы или видео отменяет черновик. Его также отменяют другая команда, панель, смена источника или controller, переход в фон, ошибка, Back и dispose. При отмене UI возвращается к актуальной позиции. Поздние события прежнего controller не меняют новый поток.

Timer скрытия срабатывает после 4 секунд бездействия во время воспроизведения. Он действует независимо от фокуса кнопок и шкалы. KeyDown/KeyRepeat, изменение фокуса, касание и seek обновляют timer. Позиционные события воспроизведения его не продлевают.

Во время удержания seek controls остаются видимыми, в том числе на границе видео. После отпускания отсчитываются новые 4 секунды. На паузе, при завершении и в панели выбора controls не скрываются.

При скрытии focus получает само видео. Следующее Up/Down показывает управление и переводит focus на Back/Play после layout. Скрытые controls исключены из focus. Play/Pause/PlayPause с media-кнопок работают также при focus кнопок меню. Во время панели эти команды не управляют фоновым player.

Серии в карточке аниме и панели player упорядочены по числовому номеру от последней к первой. Номер выводится один раз в видимой и семантической подписи, собственное название сохраняется. Отметка просмотра отличается от текущего выбора. TV-действие «Смотреть» в сведениях списка использует правило anime domain и доступный актуальный список серий; иначе открывает полную карточку. Подробности — в [карточке аниме](12_anime_details.md).

Порядок частей и действие полной карточки описаны в [спецификации карточки аниме](12_anime_details.md). Панель серий сразу показывает текущую серию и переводит focus на неё, даже если она далеко от начала списка. Up/Down прокручивают выбранную строку в видимую область. Выбор того же качества/серии или отмена панели не перезагружают поток. После закрытия chooser focus возвращается видео. Следующее OK меняет play/pause, Left/Right выполняют seek.

После окончательного отказа запуска или прерывания focus получает «Повторить». OK делает один ручной retry с новым бюджетом. После восстановления focus возвращается управлению видео. Поздний выбор от уже закрытой initialization игнорируется.

Player использует immersiveSticky. При dispose он возвращает manual system UI без overlays, как ожидает TV-приложение. Не оставлять timers, listeners или focus nodes после ухода. Сохранение позиции при качестве и сброс при серии задаёт [playback](04_playback.md).

<a id="5-загрузка-и-визуальные-состояния"></a>
## 4. Загрузка и визуальные состояния

Каталог показывает скелетоны постеров с той же геометрией ленты, что загруженная страница; левое меню остаётся доступным. Карточка серии использует компактный вариант общей MediaCard с превью, номером, названием и подтверждённым состоянием просмотра. Вложенная кнопка Play не показывается; активируется вся карточка. Скелетоны сохраняют геометрию карточки и не получают focus.

Один skeleton-контейнер управляет shimmer всех своих форм; вложенные изображения используют его, не создавая дополнительные анимации. При системном отключении анимации формы остаются видимыми без shimmer. Заглушки исключены из Semantics и не принимают focus.

Длинные названия и метаданные ограничены строками с ellipsis. Число строк описания вычисляется по доступной высоте над кнопками и масштабу текста; последняя видимая строка получает многоточие. При недоступном постере верхняя сцена сохраняет базовый фон. Вход оформлен общей темой; кнопка видимости пароля доступна пультом и касанием.

Экранные регрессии используют [общий TV golden-профиль](../05_01_widget_and_golden_tests.md#2-общие-профили-полноэкранных-golden). Масштаб 130% и адаптацию 640×360 проверяют widget-тесты. PNG-сравнение дополняют проверка пультом и Android E2E.

<a id="6-вход-с-пульта"></a>
## 5. Вход с пульта

Интро, начальный focus и результат входа и отмены задаёт [контракт входа](01_authentication.md#старт-и-экран-входа).

При закрытой клавиатуре Down ведёт от логина к паролю, затем к «Войти» и «Отмена». Up идёт обратно. KeyDown и KeyRepeat используют один порядок. Up на логине и Down на последней строке оставляют focus на текущей цели. Left/Right редактируют текст. Right в конце пароля переводит focus на кнопку видимости, Left возвращает в пароль. «Далее» экранной клавиатуры переводит focus в пароль, «Готово» отправляет форму. Во время входа поля недоступны, а отмена доступна. При сбое отмены последняя кнопка предлагает повтор. Focus nodes освобождаются вместе с экраном.

Регрессии проверяют позднюю серию 20 из 24, переход до последней стрелками и OK, отмену панели, возврат к той же карточке, пустое избранное и повтор после ошибки избранного. Android E2E дополняет widget-проверки переходами пультом и native playback. Экранная клавиатура и раскладка кнопок конкретного физического TV остаются отдельной ручной проверкой.

Аппаратный ввод проверяйте через [Directional Pad эмулятора](../../tool/e2e/README.md#directional-pad-эмулятора).

На корне содержимого Back раскрывает меню на активном разделе. Из раскрытого меню Back на неглавном разделе возвращает на Главную; в меню Главной открывает подтверждение «Выйти из приложения?» с действиями «Остаться» и «Выйти». Начальный фокус получает «Остаться». Оболочка передаёт системной навигации Android обе фазы аппаратного Back. Если редактирование в поиске завершилось по событию нажатия, обработчик поля принимает и отпускание этой же кнопки. Отдельное следующее нажатие закрывает подтверждение. Пока подтверждение открыто, отложенные callbacks оболочки не переводят focus на содержимое за диалогом. Отмена восстанавливает исходный контекст. Подтверждение закрывает Android-приложение штатным платформенным способом и сохраняет аккаунт; logout выполняется отдельно. Логотип не запускает закрытие приложения. На iOS программное завершение не добавляется.

Каталог выбранного жанра, года, режиссёра или автора показывает сортировку сверху справа. Правая панель выбора, черновик/применение, управление пультом и возврат фокуса описаны в [контракте сортировки](09_catalog_filters.md#6-сортировка-фокус-отмена-и-восстановление). Общее закрытие правой панели по Left действует только для панелей с таким контрактом; сортировка — исключение, в котором Left и Right не закрывают панель.

Кнопки предыдущей и следующей серии выбирают ближайший доступный номер ниже/выше текущего, включая пропуски в нумерации. На границе списка недоступная кнопка скрыта и исключена из фокуса. Переключение использует обычную смену серии: позиция сбрасывается, качество сохраняется, прежний native controller освобождается. Кнопки player используют общие визуальные роли из спецификации 11. В панелях с контрактом закрытия Left закрывает панель без применения черновика и восстанавливает исходный фокус (в player — фокус видео). Right в левом меню сворачивает его, возвращая последнюю доступную карточку или действие содержимого.

## Масштаб текста и доступность ошибок

Основной шрифт и семантические типографические роли заданы [визуальной системой](11_visual_system.md). Платформенные размеры учитывают системный масштаб текста.

| Роль TV | Диапазон 960×540 → 1280×720 | Выражение и основа |
| --- | ---: | --- |
| Заголовок выбранного тайтла | 29 → 39 | `20.sp.clamp(28, 56)`, Manrope 800 |
| Заголовок ленты | 18 → 20 | `14.4.sp.clamp(18, 28)`, Manrope 800 |
| Название карточки ленты | 14 → 14 | `12.sp.clamp(14, 18)`, Manrope 600 |
| Год карточки каталога/избранного | 15, без изменения | `labelLarge`, mobile `labelMedium` |
| Заголовок страницы аниме | 22 → 26 | `16.5.sp.clamp(22, 26)`, `headlineLarge`/`headlineMedium` |
| Описание и метаданные | 16 → 16 | `13.sp.clamp(16, 18)`, высота строки 1.5 |
| Название серии | 16 → 18 | `13.7.sp.clamp(16, 18)` |
| Подпись серии | 14 → 15 | `12.5.sp.clamp(14, 16)` |
| Заголовок секции | 20 → 24 | `15.8.sp.clamp(20, 24)` |
| Название жанра | 14 → 15 | `12.5.sp.clamp(14, 16)` |
| Действие инспектора и поиска | 14 → 16 | `13.sp.clamp(14, 16)` |

Шкала применяется к названным поверхностям без глобального масштабирования темы. Сохраняются типографическая иерархия, системный `textScaler` и размеры областей касания; визуальные роли принадлежат спецификации 11. Описание ограничено шириной 720 logical pixels. Измерение высоты карточки серии использует те же роли подписи и названия, что и готовая карточка. Таймер player использует табличные цифры.

Компактные фильтры метаданных имеют визуальный минимум 36–48 и область взаимодействия 48 logical pixels; высота растёт по масштабированному тексту. Визуальный минимум строк выбора — 56–64; TvChoiceTile.rowExtentOf дополнительно учитывает текст и внешние отступы. Шапка меню растёт по тексту; длинные подписи допускают две строки при увеличении, имя аккаунта сохраняет ellipsis. Фокус и выбранная серия остаются видимыми после D-pad-переходов; Left/Right/OK и возврат фокуса сохраняют прежний контракт.

При увеличенном системном тексте полная карточка растёт по содержимому и прокручивает выбранное действие или серию в видимую область. Постер внутри подробностей сохраняет пропорции; начальный фокус и Back следуют правилам карточки. ТВ-проверки используют 130% в 960×540, 1280×720 и 640×360.

Ошибка входа доступна как Semantics liveRegion: новое сообщение объявляется средствами TalkBack, а focus после отказа остаётся на поле повторного ввода пароля. Сообщение не озвучивается отдельным дублирующим вызовом announce.

## Устойчивость состояний интерфейса

Общие цвета, состояния, роли текста и фокусная рамка задаются [визуальной системой](11_visual_system.md). Hover/focus/pressed остаются различимыми, а контраст текста относительно фона сохраняется. Размеры областей управления и порядок пульта остаются частью этого TV-контракта.

TvStateView сохраняет центрирование обычного состояния и прокручивает длинное содержимое. Заголовок с сообщением имеет общий Semantics liveRegion; фокус кнопки повтора раскрывает её в видимую область. Ошибка дозагрузки каталога сохраняет карточки, ограничивает текст доступной высотой и оставляет повтор по OK. Пустой список серий предлагает «Обновить серии»; Down с избранного достигает этого действия, успешный повтор возвращает доступные выпуски.

Форма входа допускает перенос бренда и надписи загрузки. Фокус раскрывает логин, пароль или отправку при увеличенном тексте и открытой клавиатуре. Повторная отправка во время входа игнорируется. Обработка отказа описана в [контракте входа](01_authentication.md#старт-и-экран-входа).

Жанры учитывают масштаб и в числе колонок, и в высоте двух строк. При 200% на узком телефоне список становится одноколоночным. Полная метка доступна в semantics, даже при ellipsis. Пульт сохраняет порядок по строкам и выбор только по OK.

Anime/genres/player показывают безопасное message известного Failure; неожиданное исключение заменяется сообщением с доступным повтором. Обработчик ошибки маршрута не выводит URI/параметры и не записывает их в лог; «На главную» восстанавливает каталог. Поздний ответ прежнего anime-запроса не меняет подтверждённое избранное после смены параметров карточки.

## Стартовый экран

StartupScreen показывает логотип и статус проверки доступности сайта, затем сохранённой сессии. Полей ввода и интерактивных пунктов во время проверки нет. Форма входа и protected router закрыты до результата; Back не открывает их в обход проверки.

На ошибке начальный фокус получает «Попробовать снова», OK делает один повтор. После нажатия кнопка и прежняя ошибка скрываются до результата, повторный OK не создаёт параллельную операцию. Длинное сообщение прокручивается, фокус раскрывает кнопку в видимую область. Статус и ошибка объявляются как liveRegion.

При открытии главной с восстановленной сессией начальный фокус получает каталог. Android fixture E2E проверяет [переходы запуска и входа](01_authentication.md#старт-и-экран-входа).

Карточки используют [общую геометрию и метки](11_visual_system.md#значки-и-общие-визуальные-элементы). Рейтинг показывается с одной цифрой после запятой без знаменателя, например `★ 8,7`. Семантическая подпись — «Рейтинг 8,7 из 10». Некорректное значение скрывается. Фон карточки сериала доходит до боковых границ SafeArea. Внутренние отступы текста и действий сохраняются.
