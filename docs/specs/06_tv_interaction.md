# 🎮 TV-взаимодействие | AniStar TV

Ориентир UX — YouTube для телевизоров; границы адаптации и правила будущих изменений закреплены в [ADR-0008](../adr/0008-youtube-tv-interaction-reference.md).

## 1. Focus и активация

Интерактивная плитка должна быть доступна стрелками пульта и иметь видимый focus, Semantics button/focused и semanticLabel. Touch использует то же действие, что и пульт. Контролируемый экран не должен зависеть от наличия клавиатуры или указателя мыши.

TvFocusable принимает Enter, Select/OK, Space и gameButtonA. Первый KeyRepeat распознаёт удержание; последующие повторы не повторяют действие.

| Вход | Поведение |
| --- | --- |
| KeyDown без long action | Однократный onPressed |
| KeyDown при наличии long action | Запомнить клавишу, без таймера и немедленного открытия |
| KeyUp той же клавиши без KeyRepeat | onPressed |
| Первый KeyRepeat удерживаемой клавиши | Немедленно onLongPressed, ещё до отпускания |
| Потеря focus или dispose до release | Отменить ещё не распознанное удержание; ничего не открыть |
| Touch tap | Установить focus, вызвать onPressed |
| Touch long press | Установить focus, вызвать onLongPressed без короткого действия |

Длинное действие вызывается при системном KeyRepeat. Задержку определяет устройство, фиксированного порога в три секунды нет. Устройства без repeat не распознают долгое OK; touch использует штатный onLongPress. Остаток распознанного удержания (повторы и KeyUp) поглощается до передачи фокусу, чтобы не нажать первую кнопку новой панели. Нельзя одновременно открыть detail и выполнить favorite action.

## 2. Каталог и боковые панели

Каталог, избранное и карточка аниме используют TvBackdrop за прозрачным Scaffold. В каталоге нет верхних вкладок и toolbar: навигация находится слева. Шапка TvHeaderSurface остаётся на экранах с AppBar, в том числе в карточке сериала.

Левое меню без фокуса показывает иконки, с фокусом — иконки и подписи. В раскрытом меню видны название приложения и логин подтверждённого аккаунта. Порядок пунктов: Главная → Избранное → Жанры → Выйти из аккаунта → Обновить каталог → Логи. Недоступные действия пропускаются; в release нет логов. Выбранный раздел сохраняет выделение без фокуса, а сфокусированный пункт получает тёмную фиолетовую плашку со светлой акцентной рамкой и мягким свечением.

| Контекст | Клавиша | Поведение |
| --- | --- | --- |
| Первая карточка любого ряда | Left | Фокус текущего раздела в левом меню |
| Меню | Up / Down | Предыдущий / следующий доступный пункт; на краю остановка |
| Меню | OK | Открыть раздел или выполнить выбранное действие |
| Меню | Right | Вернуть последнюю доступную карточку либо действие содержимого |
| Раскрытое меню | Back | Свернуть меню и вернуть фокус содержимому |
| Первый ряд карточек | Up | В каталоге выбранного фильтра — кнопка сортировки; на главной/в избранном — остаться в сетке |
| Правая граница ряда | Right | Остаться на карточке |

При первом открытии загруженного каталога фокус получает первая карточка. После выбора раздела фокус остаётся на его пункте меню, включая пустое избранное. Смена Главная/Избранное заменяет только содержимое: левое меню, его FocusNode, прокрутка списка пунктов и текущее раскрытие сохраняются. Открытие жанров и возврат Back сохраняют исходное меню и его фокус. Right переводит фокус к карточкам или кнопке «Перейти на главную». После удаления последней карточки избранного фокус возвращается в меню; при ошибке загрузки — на кнопку повтора. Навигация по пунктам без OK не меняет раздел и не выполняет действия.

Меню занимает 88 logical pixels в свёрнутом состоянии и раскрывается до 264 поверх края каталога. Содержимое затемняется; касание затемнения возвращает фокус содержимому. Раскрытие не меняет геометрию сетки. Возврат из detail сохраняет выбранную карточку; её фокус прокручивает её в видимую область. Дозагрузка возможна при extentAfter <500 logical pixels или фокусе в последних двух рядах, только из Ready с hasMore. Защита запросов и retry описаны в [пагинации](03_page_loading.md).

CatalogLayout использует ширину области содержимого после места, отведённого левому меню: 2 колонки при ширине меньше 600, затем 3 / 4 / 5 / 6 при порогах 600 / 820 / 1180 / 1700 logical pixels. Loading использует ту же геометрию. Отдельные заголовок «Каталог», счётчик загруженных карточек и постоянные подсказки про OK отсутствуют.

Долгое OK / касание открывает FavoriteActionsSheet через общий showTvSideSheet: панель выезжает справа, занимает до 440 logical pixels по ширине и всю доступную высоту. Фон затемняется, фокус остаётся внутри панели. Left, Back, наружное касание или «Закрыть» закрывают панель; доступный исходный элемент снова получает фокус. Закрытие во время запроса не отменяет уже отправленное изменение сайта.

Панель сначала читает свежий статус, показывает loading, затем одно определённое действие. Ошибка предлагает «Обновить статус» и фокусирует его: OK повторяет чтение. Во время mutation повторное изменение недоступно. Само открытие панели не изменяет избранное.

В карточке сериала focus начинается на кнопке «Смотреть» с первой непросмотренной серией; при отсутствии серий — на избранном. Left/Right переключают эти действия. Down с любого действия ведёт к первой плитке сетки, то есть к последней серии, независимо от ширины постера. Up из первого ряда возвращает основное действие и начало scroll view. Up с действий ведёт к ряду меток категорий/жанров, а следующий Up — к кнопке возврата в AppBar. Down с возврата ведёт к меткам, затем к основному действию. Без кликабельных меток остаётся прямой переход между действиями и возвратом. Подробные правила и переходы из левого меню описаны в [жанрах и фильтрах](09_catalog_filters.md). После ухода в player и возврата маршрут сохраняет focus выбранной серии. В длинной сетке каждая сфокусированная серия прокручивается в видимую область.

После смены параметров detail/route данные загружаются заново; старый Future не определяет содержимое нового экрана. Выход и смена origin закрывают protected navigation и панели предыдущего аккаунта.

## 3. Управление player

После native pause или завершения серии controls появляются и остаются видимыми. Это правило действует и для остановки без нажатия кнопки в приложении. Существующий controller сохраняется; дополнительные HTTP-запросы не нужны.

Команды воспроизведения требуют существующего controller. При фокусе самого видео действует таблица ниже; кнопки и шкала имеют отдельные правила. Открытая панель выбора не должна передавать команды фоновому player.

| Клавиша | Действие |
| --- | --- |
| OK / Enter / Space / mediaPlayPause / gameButtonA | Play/pause |
| mediaPlay | Воспроизвести; повторная команда не ставит на паузу |
| mediaPause | Приостановить; повторная команда не запускает видео |
| Left / Right | Короткое нажатие: seek −10 / +10 секунд; удержание ускоряет повтор, с ограничением диапазона |
| Up | Показать меню и перевести focus на «К сериям» |
| Down | Показать меню и перевести focus на кнопку Play/pause |
| Back | Закрыть player и освободить native ресурсы |

Возврат к сериям расположен сверху слева. Над нижним рядом кнопок проходит шкала времени с текущей и буферизованной позицией; ниже видны время / длительность. В нижнем ряду слева направо: Play/pause → −10 секунд → +10 секунд → Предыдущая серия → Следующая серия → Серии → Качество. Недоступные действия не выводятся. Полноэкранной кнопки нет; постоянные инструкции про клавиши отсутствуют. Иконки имеют семантические имена и tooltip.

На кнопках Left/Right перемещают фокус внутри ряда без seek. Down с возврата ведёт на шкалу, затем в нижний ряд; Up из ряда возвращает на шкалу, затем к возврату. После шкалы фокус возвращается к запомненной кнопке ряда. Up с возврата или Down из нижнего ряда возвращает фокус самому видео. На шкале Left/Right используют то же ускоряющееся удержание, что и на видео; касание также меняет позицию. Фокус шкалы заметен по толщине линии и размеру бегунка. OK на кнопке выполняет только её действие.

Play/pause обрабатывается на KeyDown без повторной команды на KeyRepeat; перемещение по меню допускает repeat. На видео и шкале Left/Right сразу дают шаг 10 секунд, затем повторяются каждые 500 мс по собственному таймеру (первый повтор через 500 мс). Размер шага по длительности удержания: до 2 секунд — 10 секунд; 2…<4 — 20; 4…<6 — 30; 6…<8 — 60; от 8 — 120 секунд. KeyRepeat не добавляет seek и не меняет скорость. Отпускание текущего направления останавливает повтор; новое удержание и смена направления начинают с 10 секунд. Отпускание прежнего направления не отменяет новое. Уход фокуса со шкалы/видео, другая команда, панель, смена источника, фон, Back и dispose отменяют удержание. На границах повтор не отправляет одинаковые native seek.

Timer скрытия — 4 секунды бездействия во время воспроизведения независимо от фокуса кнопок/шкалы. KeyDown/KeyRepeat, изменение фокуса, касание и seek обновляют timer; позиционные события воспроизведения его не продлевают. Пока длится удержание seek, controls видимы, в том числе на границе видео; после отпускания отсчитываются новые 4 секунды. На паузе, при завершении и в панели выбора controls не скрываются. При скрытии focus получает само видео; следующее Up/Down показывает управление и переводит focus на Back/Play после layout. Скрытые controls исключены из focus. Play/Pause/PlayPause с media-кнопок работают также при focus кнопок меню; во время панели они не управляют фоновым player.

Серии в карточке аниме и панели player упорядочены по числовому номеру от последней к первой. В сетке чтение идёт слева направо, затем вниз. Кнопка «Смотреть» в hero открывает первую непросмотренную серию по возрастанию номера, учитывая отметки HTML и подтверждённую историю аккаунта. После обновления истории меняются текст и действие кнопки; фокус сохраняется. Если просмотрены все доступные серии, кнопка предлагает первую для повторного просмотра. Панель серий сразу показывает текущую серию и переводит focus на неё, даже если она далеко от начала списка. Up/Down прокручивают выбранную строку в видимую область. Выбор того же качества/серии или отмена панели не перезагружают поток. После закрытия chooser focus возвращается видео; следующее OK меняет play/pause, Left/Right выполняют seek. После окончательного отказа запуска или прерывания focus получает «Повторить»; OK делает один ручной retry с новым бюджетом. После восстановления focus возвращается управлению видео. Поздний выбор от уже закрытой initialization игнорируется.

Player использует immersiveSticky; при dispose возвращается manual system UI без overlays, как ожидает TV-приложение. Не оставлять timers, listeners или focus nodes после ухода. Сохранение позиции при качестве и сброс при серии задаёт [playback](04_playback.md).

## 5. Загрузка и визуальные состояния

Каталог показывает скелетоны постеров с теми же отступами и сеткой, что загруженная страница; левое меню остаётся доступным. Карточка сериала показывает отдельные формы постера, текста и кнопки; высота hero и число столбцов серий общие для loading и ready. Число столбцов серий вычисляется после горизонтальных отступов.

Один skeleton-контейнер управляет shimmer всех своих форм; вложенные изображения используют его, не создавая дополнительные анимации. При системном отключении анимации формы остаются видимыми без shimmer. Заглушки исключены из Semantics и не принимают focus.

Длинные названия и метаданные ограничены строками с ellipsis. Число строк описания вычисляется по доступной высоте над кнопками и масштабу текста; последняя видимая строка получает многоточие. Фоновой картинке hero не показывают error icon, чтобы он не перекрывал текст. Вход оформлен общей темой; кнопка видимости пароля доступна пультом и касанием.

Golden-проверки закрепляют каталог, свёрнутое/раскрытое меню, правые панели, плеер, экран входа, загрузку и длинное содержимое карточки на 960×540 и 1280×720. Изменение baselines требует просмотра PNG; генерация не заменяет проверку пультом и Android E2E.

## 6. Вход с пульта

Если подтверждённой сессии нет, начальный focus экрана входа получает логин. Действие «Далее» экранной клавиатуры переводит focus в пароль, «Готово» отправляет форму. После отказа пароль очищается и снова получает focus для повторного ввода. При закрытой экранной клавиатуре Down переводит логин → пароль → «Войти», Up переводит «Войти» → пароль → логин. KeyDown и KeyRepeat используют одинаковый явный порядок; Up на логине остаётся в логине. После ошибки Down с «Войти» открывает доступ к «Повторить проверку сессии», Up возвращает к «Войти»; однострочные поля не перехватывают эти клавиши как движение курсора. Left/Right остаются доступны для редактирования текста. Поля отключены только на время запроса. Focus nodes освобождаются вместе с экраном.

Регрессии проверяют позднюю серию 20 из 24, переход до последней стрелками и OK, отмену панели, возврат к той же карточке, пустое избранное и повтор после ошибки избранного. Android E2E дополняет widget-проверки переходами пультом и native playback. Экранная клавиатура и раскладка кнопок конкретного физического TV остаются отдельной ручной проверкой.

В эмуляторе отдельно проверяется `Extended Controls → Directional Pad`: Flutter `sendKeyEvent` и Android `input keyevent` обходят kernel keyboard device. E2E preflight требует hardware input с четырьмя стрелками; локальному API 36 TV-профилю нужны `hw.dPad=yes` и `hw.keyboard=yes` с Cold Boot после изменения. Инструкция находится в [разработке и тестировании](../05_development_and_testing.md#directional-pad-эмулятора).

Каталог выбранного жанра показывает текущую сортировку у названия. Правая панель выбора, черновик/применение, управление пультом и возврат фокуса описаны в [контракте сортировки](09_catalog_filters.md#сортировка-выбранного-жанра).

Кнопки предыдущей и следующей серии выбирают ближайший доступный номер ниже/выше текущего, включая пропуски в нумерации. На границе списка недоступная кнопка скрыта и исключена из фокуса. Переключение использует обычную смену серии: позиция сбрасывается, качество сохраняется, прежний native controller освобождается. Кнопки player используют общий AppFocusStyle. Left в правой панели закрывает её без применения черновика и восстанавливает исходный фокус (в player — фокус видео). Right в левом меню сворачивает его, возвращая последнюю доступную карточку или действие содержимого.

## Масштаб текста и доступность ошибок

Семейство Inter загружается из UI Kit в реальных начертаниях 400/500/700. Заголовки и названия карточек используют 700; подписи жанров, номера серий и имя аккаунта — не меньше 14 logical pixels до системного масштабирования. Описание ограничено шириной 720 logical pixels при прежнем основном размере 18; заголовки и действия используют всю доступную колонку. Таймер player использует табличные цифры.

Высота фильтров не меньше 48 и растёт по масштабированному тексту с отступами. Виртуализированные строки выбора используют TvChoiceTile.rowExtentOf: 64 при обычном тексте, больше при увеличении. Шапка меню растёт по тексту; длинные подписи допускают две строки при увеличении, имя аккаунта сохраняет ellipsis. Фокус и выбранная серия остаются видимыми после D-pad-переходов; Left/Right/OK и возврат фокуса сохраняют прежний контракт.

При увеличенном системном тексте hero карточки сериала имеет общую со skeleton минимальную высоту, учитывающую масштаб, и растёт дальше по содержимому. Постер сохраняет базовую геометрию; текст не сжимается ради кнопок. Начальный фокус на «Смотреть»/избранном и возврат Up из серий прокручивают выбранное действие в видимую область. При обычном масштабе сохраняется возврат к началу страницы. Направления пульта и действия OK не меняются. Проверяются 130% и 200% в 960×540, 1280×720 и узком landscape 640×360.

Ошибка входа доступна как Semantics liveRegion: новое сообщение объявляется средствами TalkBack, а focus после отказа остаётся на поле повторного ввода пароля. Сообщение не озвучивается отдельным дублирующим вызовом announce.

## Устойчивость состояний интерфейса

Основные FilledButton в тёмной теме используют тёмный onPrimary из AppPalette.background. Hover/focus/pressed накладывают светлый state layer, сохраняя контраст текста не ниже 4,5:1; фокус отмечается рамкой 3 logical pixels. Темы, роли текста, размеры кнопок и порядок пульта общие для входа, карточки и восстановления после ошибки.

TvStateView сохраняет центрирование обычного состояния и прокручивает длинное содержимое. Заголовок с сообщением имеет общий Semantics liveRegion; фокус кнопки повтора раскрывает её в видимую область. Ошибка дозагрузки каталога сохраняет карточки, ограничивает текст доступной высотой и оставляет повтор по OK. Пустой список серий предлагает «Обновить серии»; Down с избранного достигает этого действия, успешный повтор возвращает доступные выпуски.

Форма входа допускает перенос бренда и надписи загрузки, раскрывает логин/пароль/отправку/повтор при фокусе, включая увеличенный текст и экранную клавиатуру. Повторная отправка во время входа игнорируется до проверки формы: пароль очищается после завершения попытки, а не из-за второго нажатия. Имя пользователя сохраняется после отказа.

Жанры учитывают масштаб и в числе колонок, и в высоте двух строк. При 200% на узком телефоне список становится одноколоночным. Полная метка доступна в semantics, даже при ellipsis. Пульт сохраняет порядок по строкам и выбор только по OK.

Anime/genres/player показывают безопасное message известного Failure; неожиданное исключение заменяется сообщением с доступным повтором. Обработчик ошибки маршрута не выводит URI/параметры и не записывает их в лог; «На главную» восстанавливает каталог. Поздний ответ прежнего anime-запроса не меняет подтверждённое избранное после смены параметров карточки.
