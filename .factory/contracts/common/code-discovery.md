# Project discovery

Choose available tools for the assigned question; no mandatory sequence:

- README/indexes: project structure and relevant documentation.
- Current Graphify: related components, consumers and documents.
- `rg --files` / `rg`: exact files, symbols and text; use ordinary search if Graphify is unavailable or stale.
- `git diff`, when relevant: changed files; inspect affected dependencies and tests beyond the diff.

Confirm index/graph results in original files; a graph edge alone does not prove behavior.
Cite verified `path:line` references when reporting evidence; distinguish no matches from incomplete search.
Stay within assignment permissions and stop when evidence answers the question. Graphify is not a required gate.
