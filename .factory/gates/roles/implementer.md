# Implementer completion gates

Return the current assignment identity, source hash, changed files, tests tied
to the intended behavior and any remaining limitation. For a write-only stage
return `WRITES_READY` with `checks: []`. If assigned a registered generation
command, include its own real receipt under the writer's dispatch. Generation
does not supply a verification result.

Stop dependent edits and identify any scope, source or semantic blocker. On a
correction, preserve the finding ID and the true owner. A completed author
handoff does not close a finding or establish acceptance.
