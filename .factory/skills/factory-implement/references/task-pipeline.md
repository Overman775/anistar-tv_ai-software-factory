# Task guidance

For a bug, preserve reproduction and expected behavior. Add BugHunter only
when root cause is uncertain; diagnosis does not change the source. Implement a
bounded fix and meaningful regression coverage. Choose combined/separated authors
by risk, not diff length. Independent review and current evidence follow the
selected graph; auth, networking trust and lifecycle fixes require separated roles.

Use `.factory/workflow/orchestration.md`, shared gates, state and finalize contracts.
