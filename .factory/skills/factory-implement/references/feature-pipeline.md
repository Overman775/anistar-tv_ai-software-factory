# Feature guidance

Feature work starts from bounded request/task or approved plan. Assess risk
and split observable behavior into vertical slices. One Developer may span layers;
several require clear ownership and a shared interface. Test the integrated
scenario, update docs/specs, run applicable project gates and final independent
review unless the low-risk policy explicitly permits solo. A real feature normally
needs independent review. Generalist+review is allowed only by selection policy.
Required deferred behavior stays tracked until final acceptance.

Use `.factory/workflow/orchestration.md`, shared gates, state and finalize contracts.
