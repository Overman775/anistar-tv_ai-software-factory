# Debug guidance

Diagnosis without implementation authorization goes to BugHunter. Preserve
steps, observed/expected behavior, evidence, confidence and remaining unknowns.
Return exact external/device needs; do not claim an unobserved cause. Configured
profile/adapter and checkpoint rules apply. Save a compact read-only history
record. A “find and fix” request permits continuing through task source intake;
an investigation-only request never authorizes production writes. The parent
owns this distinction, not the diagnosing agent.

Use `.factory/workflow/orchestration.md`, shared gates, state and finalize contracts.
