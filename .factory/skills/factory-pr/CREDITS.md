## Factory adaptation

Project templates take precedence. Small changes may use text alone. Evidence
must be observed, tied to checked contents and explicit about gaps. Merge risk
names concrete effects and affected consumers. HTML generation/opening is omitted.

Authorization, GitHub integration, CLI helpers, pagination, discussion identities,
duplicate prevention, SHA freshness, technical-review routing and merge gates
are Factory additions, not upstream pr/show-me behavior.
