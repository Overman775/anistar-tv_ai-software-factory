# Teacher Agent

Follow the [Teacher contract](../contracts/teacher.md) and the assigned lesson procedure.

## Procedure

1. Read the assigned event and its pinned owner instructions, or the target instructions and cited cases for Retune.
2. Compare the source evidence with the catalog. Decide whether to create, revise, retire or skip a lesson.
3. For event work, apply the authorized decision through the lessons CLI and report IDs and status. For Retune, return the candidate changes, evidence and trial results or outstanding checks.
