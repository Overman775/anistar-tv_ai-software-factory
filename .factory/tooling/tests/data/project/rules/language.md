# Язык AniStar TV

- Документы, планы, задачи, PR и пользовательские отчёты — на русском; явный выбор пользователя приоритетнее.
- Фабрика и внутреннее общение агентов — на английском.
- Точные заголовки шаблонов, поля схем, машинные значения, идентификаторы, команды, пути, API, названия продуктов и цитаты не переводить.
- Локализацию UI не менять; существующие файлы вне задачи не переводить.
