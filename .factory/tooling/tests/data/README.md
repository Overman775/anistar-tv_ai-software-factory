# Tooling fixtures

Configuration and project policy captured from the bundled baseline on 2026-11-01.
These are test inputs, independent of installed consumer settings. The fixture helper
copies shared instructions/code and these inputs into a disposable bundle. Tests
replace executable checks with local fixture commands; they do not call models or
application tools. AniStar-specific data exercises policy selection as sample data,
not a dependency on the AniStar application or its working files.
