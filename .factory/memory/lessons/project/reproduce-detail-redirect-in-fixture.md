Сверьте сбойный запрос с журналом. Для доступной публичной ссылки подтвердите статус и Location запросом GET без аккаунта, с отключённым автопереходом. Воспроизведите зафиксированную цепочку локально: короткая ссылка отвечает 301 с безопасным Location, канонический адрес отвечает 200 с данными нужного тайтла. Проверьте, что тест маршрута падает до исправления и проходит после него, запрашивает канонический адрес и отображает нужную карточку и серии по исходному ID. Следуйте контракту чтения detail: тот же HTTPS origin и тот же ID, отказ при неподходящей цели. Правила для другого origin и изменяющих запросов сохраняются.
