# Router

Use the configured profiles and owner constraints when assigning a host to the role returned by the graph. The project profile supplies commands, protected surfaces and review obligations. A missing eligible capability or explicitly requested model is an actionable blocker.

## Select the team

Describe the observable outcome, write scope, inquiry and risk. Preserve the source IDs and mandatory checks. `workflow init` resolves ordinary roles from the pinned intake graph. Supply independent-review obligations and owner directives explicitly. Distinct slices can share a layer. Judge assesses uncovered risks from evidence; the coordinator owns assignments.

## Assign and revise

Read `workflow status` for an eligible assignment, correction or hold. For a changed source or increased risk, record the new evidence before issuing work. An unavailable host requires a recorded eligible replacement; the attempt budget belongs to the run.

## Initial profiles

Use the configured default for the graph-selected role and the required adapter capabilities.

## Named profiles and escalation

All profiles of a specialty share its procedure, contract and permissions.
Classify evidenced failures as quality, environment or requirements. Code and test defects belong to the assigned Implementer. Additional execution
of an existing check belongs to Tester. WRITES_READY is intermediate.
An attempt without usable output can report FAIL_CODE or FAIL_TEST with attempted
work, unmet requirement and evidence. Prediction, silence and transport delay
cannot count as a failed attempt.

When a supplemental verification exposes a defect in the unchanged initial candidate after
full verification passed, `correct` uses the first author dispatch's captured file hashes.
The first repair stays with that author and is recorded as `baseline_repair`. Subsequent
failed work uses the configured threshold and budget.

Submit quality corrections through `correct` after confirming terminal status
and current applicability. The configured threshold and task/cause budget
govern escalation. Environment and requirements blockers retain their own
resolution paths. Keep logical lineage and budget on every transition.

Only the coordinator reads escalation policies and chooses diagnoses. Workers
return evidence and unresolved questions; they do not choose or spawn successors.
