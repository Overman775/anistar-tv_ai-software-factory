# AniStar TV

**AniStar TV**: клиент AniStar на Flutter для Android TV и телефонов. Телевизор остаётся основной платформой с управлением пультом; мобильная версия использует сенсорный интерфейс.

Каталог, карточки и серии загружаются напрямую с AniStar через HTTP и HTML/JSON5. Общий `AnistarClient` возвращает нормализованные DTO; `HtmlAnistarClient` реализует HTML-протокол. Границы и ограничения будущего REST: [ADR-0010](docs/adr/0010-normalized-anistar-contract.md). Видео воспроизводится нативно в HLS 360p/720p. Скачивание и офлайн-просмотр не поддерживаются.

## 🚀 Быстрый старт

Проект использует **FVM**, **Melos** и **Dart pub workspace**. Нужны JDK 17, Android SDK и устройство или эмулятор.

```bash
fvm install
fvm flutter pub get --enforce-lockfile
fvm dart run melos bootstrap --enforce-lockfile
fvm dart run melos run run:dev
```

Полная локальная проверка: `fvm dart run melos run check` (нужен DCM). Все команды: [Melos tooling](docs/melos_tooling.md). Команды тестов: [Разработка и тестирование](docs/05_development_and_testing.md).

Начальное зеркало: `https://v30.astar.bz`. Для `vN.astar.bz` клиент сохраняет подтверждённый номер версии и при недоступности проверяет до четырёх следующих зеркал. Другое HTTPS-зеркало задаётся через `--dart-define=ANISTAR_MIRROR_URL=https://mirror.example` или `env/dev.json`. Доступность зависит от зеркала и IP; интерактивная CAPTCHA не обходится.

При запуске введите логин и пароль существующего аккаунта AniStar. Сессия хранится в Secure Storage и проверяется при следующем запуске; пароль не сохраняется. Кнопка выхода находится в каталоге. Вкладка «Избранное» показывает список аккаунта на сайте; добавление и удаление синхронизируются с AniStar.

## 🎮 Управление на TV

| Экран | Кнопки |
| --- | --- |
| Каталог | Стрелки: фокус; короткое OK: открыть; удержание OK / долгое касание: избранное |
| Карточка сериала | OK: выбрать действие/серию; кнопка добавления/удаления избранного; Back: вернуться |
| Плеер | OK: пауза; ←/→: ±10 секунд; ↑: качество; ↓: серия; Back: вернуться |

Смена качества сохраняет позицию. Новая серия начинается с нуля. После ошибки плеер один раз получает свежую ссылку; затем доступен ручной повтор.

На телефоне доступны нижние вкладки, панели действий и сенсорный полноэкранный плеер с кнопкой поворота. Главная, избранное, каталог и карточка аниме обновляются жестом вниз от начала списка. Подробности: [мобильное взаимодействие](docs/specs/10_mobile_interaction.md).
