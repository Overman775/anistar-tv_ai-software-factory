# Окружение приложения AniStar TV

Это отдельная проектная задача, не Factory Install. Выполняется по запросу
подготовить приложение. Основная процедура — в [AniStar Install](../SKILL.md).

В реальном checkout прочитайте AGENTS.md, README.md, docs/melos_tooling.md,
docs/vcs_guidelines.md, docs/05_development_and_testing.md и tool/e2e/README.md.
При отсутствии этих документов не выдумывайте версии, команды или результаты проверок.

- Flutter/FVM/Dart: версии из .fvmrc и фактической конфигурации приложения.
- Melos и пакеты: pubspec.yaml/pubspec.lock; сохранение lockfile, без скрытого upgrade.
- Java/Android SDK/NDK: требования выбранного Flutter и Gradle; устройство/AVD по задаче.
- DCM, security tools и hooks: актуальные конфиги и scripts приложения; сохранить чужие hooks.
- Dart/DCM MCP: фактические настройки выбранного host в проекте и официальные инструкции серверов.
- Сборка, codegen, тесты и HLS fixtures: только применимые разрешённые действия по
  документации приложения. Не пересоздавать fixtures и goldens ради установки.

Официальные инструкции поставщиков определяют способ установки для ОС.
Настройки и pins приложения определяют состав. Уже данное разрешение пользователя
действует; неизвестные существенные изменения требуют уточнения. Авторизацию,
лицензии и trust пользователь подтверждает штатно. Итог: версии, реальные проверки,
непроверенные возможности и блокеры; без commit/push/публикации.
