# Anistar TV

Anistar TV is a Flutter application for viewers who navigate anime with a remote or keyboard, choose an episode and watch it in a focused native player.

## Current capabilities

- Development and production entry points.
- Typed navigation between home, anime, player and log viewer screens.
- Remote catalog loading and pagination.
- Generated AniStar Parser OpenAPI integration.
- Anime metadata and episode selection.
- Native HLS playback with TV-oriented controls and parser-managed sessions.
- Local file logging and an in-app log viewer.
- Shared themes through the local ui_kit package.

## Success criteria

- Dependency resolution and code generation complete without errors.
- Formatter, Flutter analyzer, DCM and automated tests pass.
- Android debug build succeeds on the supported local toolchain.
- Core data flow and module ownership are documented and discoverable through Graphify.
