# Исправления извлечения graphify

Локальный инструмент сопровождает extractor graphify для AniStar TV. Патч предназначен для **graphifyy 0.9.85**. Он исправляет причины
двух пустых endpoints и одиннадцати ложных self-loops в графе AniStar TV:

- Dart-строки и комментарии маскируются перед поиском объявлений. URI импортов
  и пути навигации читаются из оригинальных строк. Позиции и номера строк
  сохраняются. HTML fixtures больше не создают объявления с пустым типом.
- `$` сохраняет отдельную идентичность Dart-символа (маркер `_u0024_` в ID),
  включая определения mixin, ссылки и сопоставление stubs. `Route` и `$Route`
  больше не сливаются.
- Kotlin `super.method()` разрешается через локальную цепочку наследования.
  Внешний метод остаётся unresolved. `this.method()` и настоящая рекурсия
  сохраняются. Вызов superclass не связывается с одноимённой свободной функцией.

## Использование

Из корня проекта используйте Python, которым установлен graphify. При первом успешном применении installer патчит три проверенных файла; `--check` подтверждает совпадение их хешей с исправленной версией.

Применение меняет установленную копию graphify, а не приложение или исходники репозитория. Installer проверяет версию и SHA-256 всех трёх файлов, выполняет dry-run, допускает повторный запуск и восстанавливает оригиналы при ошибке. Применяйте его только к graphifyy **0.9.85**. После обновления graphify патч может исчезнуть; другую версию нужно отдельно проверить. Автоматически применять к ней этот diff нельзя.

Из корня проекта, используя Python той же установки, что и graphify:

```sh
"$(cat graphify-out/.graphify_python)" tool/graphify/patch_graphify.py
```

После первого применения требуется полная пересборка graphify с новым AST cache, поскольку номер версии инструмента не изменён. После неё последующие изменения обновляют готовый исправленный граф обычной командой `graphify update .`.

Полная пересборка включает весь корпус, разрешённый `.graphifyignore`: код
извлекается заново, документы читаются заново для semantic fragments. Generated
код, assets, credentials и build artifacts исключены правилами проекта.
Извлечение Dart остаётся regex-based: патч не превращает его в полный Dart AST.

## Как проверить

Проверка `--check` не меняет установленный инструмент. Regression-тесты запускаются Python того же окружения. Применение, проверку и тесты выполняйте из корня проекта:

```sh
"$(cat graphify-out/.graphify_python)" tool/graphify/patch_graphify.py --check
"$(cat graphify-out/.graphify_python)" -m unittest discover -s tool/graphify -p 'test_*.py' -v
```

Семь regression tests проверяют реальные проблемные файлы, HTML внутри строк,
импорты и навигацию, номера строк, `$` mixins в отдельном part-файле, локальный
superclass и внешний superclass. Они также проверяют сохранение настоящей
рекурсии. Массового удаления циклов или фильтрации рёбер после извлечения нет.

Доказательства выполнения полной пересборки сохраняются в ignored
`build/verification/graphify-rebuild/`: regression logs до/после, свежий AST,
semantic fragments, health summaries и резервная копия прежнего графа.
Raw health и post-build health проверяются отдельно: обычный undirected Graph
объединяет разные связи между одной парой узлов. Сырой extraction сохраняет
исходные отношения и позиции. Это ограничение формата, а не устранённый дефект.
Ссылки на внешние Python/Android библиотеки не объявляются локальными реализациями.
